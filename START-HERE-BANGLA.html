পুরো ছবিটা এক নজরে

ভালো উত্তর পাওয়ার ৪টা টিপস

  1. নিজের পরিস্থিতি বলুন: সাইটের ধরন (ব্লগ, দোকান, সার্ভিস), কোন দেশ বা শহরের জন্য, সাইট কত পুরনো, আর লক্ষ্য কী (বিক্রি, লিড, ট্রাফিক)।
  2. নিজের লেভেল বলুন: "আমি নতুন" বললে AI সহজ ভাষায় বোঝাবে। "আমি এজেন্সি চালাই" বললে পুরো ফ্রেমওয়ার্ক দেবে।
  3. শেষে কী চান সেটা বলুন: চেকলিস্ট, ৩০ দিনের প্ল্যান, ক্লায়েন্ট রিপোর্ট, নাকি সরাসরি লেখা (title, meta description)।
  4. ফলো-আপ প্রশ্ন করুন: "এটা আরও সহজ করে বলো", "ধাপ ২ কীভাবে করব?", "ফ্রি টুল দিয়ে কীভাবে করব?"

তিন লেভেলের শেখার পথ

প্রতিটা skill-এ Beginner → Intermediate → Advanced শেখার পথ আছে: - Beginner: মূল ধারণা আর প্রথম কাজগুলো। - Intermediate: নিয়মিত কাজের পুরো প্রক্রিয়া। - Advanced: বড় সাইট, ডেটা বিশ্লেষণ, জটিল সমস্যা।

AI আপনার প্রশ্নের ধরন দেখে লেভেল বুঝে নেয়। চাইলে নিজেও বলে দিতে পারেন: "আমি নতুন, সহজ করে বলো।"

এই প্যাক কী করে না

  • নিজে থেকে আপনার ওয়েবসাইটে কিছু বদলায় না। পরামর্শ দেয়, কাজ আপনি (বা আপনার ডেভেলপার) করবেন।
  • র‍্যাংকিংয়ের গ্যারান্টি দেয় না।
  • নিষিদ্ধ বা ঝুঁকিপূর্ণ কৌশল (লিংক কেনা, স্প্যাম) শেখায় না। জিজ্ঞেস করলে কেন সেগুলো ঝুঁকিপূর্ণ তা বুঝিয়ে দেয়।
  • পেইড টুল ছাড়াও কাজ করে। কোন কাজ কোন ফ্রি টুল দিয়ে করা যায় তা বলে দেয়, যেমন Google Search Console আর PageSpeed Insights।

ℹ️ Claude-এর মেনু আর বাটনের নাম মাঝে মাঝে বদলায়। নিচের নামের সাথে হুবহু না মিললে চিন্তা করবেন না, কাছাকাছি নামের অপশন খুঁজুন। Skills ফিচার কোন প্ল্যানে আছে তাও বদলাতে পারে। Skills অপশন না পেলে পদ্ধতি খ ব্যবহার করুন।

যা লাগবে: প্যাকের 1-Claude ফোল্ডার, যেখানে ১১টা .skill ফাইল আছে।

ধাপ ১: কোড চালানোর অনুমতি চালু করুন

  1. claude.ai-তে লগইন করুন।
  2. নিচে বাঁ দিকে আপনার নামে ক্লিক করুন → Settings।
  3. Capabilities ট্যাবে যান।
  4. "Code execution and file creation" সুইচটা চালু (ON) করুন। Skill চলার জন্য এটা দরকার।

ধাপ ২: Skill আপলোড করুন

  1. একই Capabilities পেজে নিচে Skills অংশ পাবেন।
  2. "Upload skill" বাটনে ক্লিক করুন।
  3. 1-Claude ফোল্ডার থেকে প্রথমে seo-router.skill বেছে নিন।
  4. বাকি ১০টা ফাইলও একইভাবে একটা একটা করে আপলোড করুন।
  5. আপলোডের পর প্রতিটা skill-এর পাশের সুইচ চালু (ON) আছে কিনা দেখে নিন।

💡 .skill ফাইল আপলোড না নিলে ফাইলের নামের শেষের .skill বদলে .zip করে দিন (যেমন seo-router.zip), তারপর আবার আপলোড করুন। দুটো আসলে একই ফাইল।

💡 সব skill লাগবে না? নতুনদের জন্য ন্যূনতম সেট: seo-router, seo-fundamentals, keyword-research, on-page-seo। লোকাল বিজনেস হলে সাথে local-seo দিন।

ধাপ ৩: পরীক্ষা করুন

একটা নতুন চ্যাট খুলে লিখুন:

আমার নতুন ওয়েবসাইট Google-এ কীভাবে আনব? আমি একদম নতুন।

উত্তর লেখার সময় Claude যদি skill পড়ে (স্ক্রিনে "Reading skill…" বা এমন কিছু দেখাতে পারে) আর লেভেল অনুযায়ী ধাপে ধাপে প্ল্যান দেয়, তাহলে সব ঠিক আছে ✅

অন্য উপায়: কোনো চ্যাটে কেউ .skill ফাইল পাঠালে ফাইলের কার্ডে "Save skill" বাটন দেখা যেতে পারে। সেখানে ক্লিক করলেও ইনস্টল হয়ে যায়।

পদ্ধতি খ: Claude Project ব্যবহার করে (Skills অপশন না থাকলে)

  1. claude.ai-তে বাঁ পাশের মেনু থেকে Projects → Create project। নাম দিন, যেমন "SEO Assistant"।
  2. প্রজেক্টের Instructions (বা "Set project instructions") ঘরে 2-ChatGPT-Gemini/chatgpt-files/00-instructions.md ফাইল খুলুন। সেখানে --- (তিনটা হাইফেন) দিয়ে একটা লাইন আছে। ওই লাইনের নিচের সব লেখা কপি করে এখানে পেস্ট করুন।
  3. Project knowledge-এ ফাইল যোগ করুন। 2-ChatGPT-Gemini/chatgpt-files ফোল্ডারের সব ফাইল দিন, বা যেগুলো দরকার সেগুলো। সবসময় রাখবেন 00-seo-router.md আর 11-glossary.md।
  4. এখন ওই প্রজেক্টের ভেতরে নতুন চ্যাট খুলে প্রশ্ন করুন।

পদ্ধতি গ: Claude Code-এ ইনস্টল (এক ক্লিকে)

আগে থেকে Claude Code ইনস্টল থাকতে হবে। টার্মিনাল হলো কম্পিউটারে লিখে কমান্ড দেওয়ার প্রোগ্রাম (Mac-এ "Terminal", Windows-এ "PowerShell")।

Mac বা Linux

  1. Finder-এ প্যাকের install ফোল্ডারে রাইট-ক্লিক করুন → "New Terminal at Folder"। এতে টার্মিনাল ওই ফোল্ডারের ভেতরেই খুলবে। (অপশনটা না দেখালে: System Settings → Keyboard → Keyboard Shortcuts → Services থেকে চালু করুন, অথবা টার্মিনালে cd লিখে ফোল্ডারটা টেনে এনে ছেড়ে দিন, তারপর Enter চাপুন।)
  2. টার্মিনালে লিখুন: bash install-claude-code.sh
  3. "Done: 11 skills installed" লেখা দেখলে Claude Code বন্ধ করে আবার চালু করুন।

Windows

  1. install ফোল্ডারে install-claude-code.ps1 ফাইলে রাইট-ক্লিক করুন → "Run with PowerShell"।
  2. "Done" দেখলে Enter চাপুন, তারপর Claude Code রিস্টার্ট করুন।

শুধু একটা প্রজেক্টের জন্য ইনস্টল করতে চাইলে স্ক্রিপ্টের শেষে প্রজেক্টের ফোল্ডারের পাথ দিন, যেমন bash install-claude-code.sh ~/my-website।

হাতে কপি করতে চাইলে: 3-coding-agents/skills/ ফোল্ডারের ভেতরের ১১টা ফোল্ডার কপি করে আপনার হোম ফোল্ডারের .claude/skills/ ফোল্ডারে রাখুন। Mac-এ এটা /Users/আপনার-নাম/.claude/skills/ (সংক্ষেপে ~/.claude/skills/), Windows-এ C:\Users\আপনার-নাম\.claude\skills\। .claude লুকানো ফোল্ডার: Mac-এ Finder-এ Cmd + Shift + . চাপলে দেখা যায়।

আপডেট বা মুছে ফেলা

  • আপডেট: নতুন ভার্সন পেলে আগের skill মুছে নতুনটা আপলোড করুন। Claude Code-এ শুধু ইনস্টল স্ক্রিপ্ট আবার চালালেই হয়।
  • বন্ধ রাখা বা মুছে ফেলা: Settings → Capabilities → Skills থেকে সুইচ বন্ধ করুন বা মুছে দিন।

ChatGPT ও Gemini-তে সেটআপ

ChatGPT আর Gemini-তে "skill" ইনস্টলের অপশন নেই। তাই আমরা একটা নিজস্ব অ্যাসিস্ট্যান্ট বানাব, যাকে নির্দেশনা (Instructions) আর জ্ঞানের ফাইল (Knowledge) দেওয়া থাকবে। ফলাফল প্রায় একই হবে।

যা লাগবে: প্যাকের 2-ChatGPT-Gemini ফোল্ডার। - chatgpt-files/: ১৪টা ফাইল (১টা নির্দেশনার ফাইল আর ১৩টা জ্ঞানের ফাইল), ChatGPT আর Claude Project-এর জন্য - gemini-files/: ৯টা ফাইল (Gemini-তে ফাইলের সীমা কম, তাই কয়েকটা একসাথে জোড়া দেওয়া)

ChatGPT: Custom GPT বানানো (সবচেয়ে ভালো ফল)

Custom GPT বানাতে সাধারণত ChatGPT-এর পেইড প্ল্যান লাগে। ফ্রি প্ল্যান হলে নিচের ChatGPT Project পদ্ধতি দেখুন।

  1. chatgpt.com-এ যান → বাঁ পাশে GPTs (বা "Explore GPTs") → উপরে ডানে + Create।
  2. Configure ট্যাবে ক্লিক করুন।
  3. Name: SEO Assistant (বা আপনার পছন্দের নাম)।
  4. Description: বাংলা ও ইংরেজিতে SEO সাহায্যকারী
  5. Instructions: chatgpt-files/00-instructions.md খুলুন। --- লাইনের নিচের সব লেখা কপি করে এখানে পেস্ট করুন।
  6. Knowledge: "Upload files" চাপুন। chatgpt-files ফোল্ডারের 00-instructions.md বাদে বাকি ১৩টা ফাইল (00-seo-router.md থেকে 12-analyze_gsc.py পর্যন্ত) আপলোড করুন।
  7. Capabilities: - ✅ Web Search চালু রাখুন, যাতে নতুন তথ্য যাচাই করতে পারে। - ✅ Code Interpreter & Data Analysis চালু রাখুন। Traffic Drop Doctor-এর স্ক্রিপ্ট চালাতে এটা লাগবে।
  8. উপরে ডানে Create (বা Update) চাপুন → "Only me" বেছে নিয়ে Save করুন।
  9. পরীক্ষা: GPT-টা খুলে লিখুন আমার নতুন ব্লগ Google-এ কীভাবে আনব?

Conversation starters-এ এগুলো দিতে পারেন: - আমার সাইটের জন্য ৩০ দিনের SEO প্ল্যান দাও - এই পোস্টের জন্য title আর meta description লিখে দাও - আমার ট্রাফিক কমে গেছে, কারণ খুঁজে দাও

ChatGPT: Project দিয়ে (ফ্রি প্ল্যানেও চলতে পারে)

  1. chatgpt.com → বাঁ পাশে Projects → New project → নাম দিন SEO।
  2. প্রজেক্ট খুলে Instructions (বা "Add instructions") ঘরে 00-instructions.md-এর --- লাইনের নিচের লেখা পেস্ট করুন।
  3. Files (বা "Add files")-এ ফাইল আপলোড করুন। - ফ্রি প্ল্যানে ফাইলের সংখ্যা সীমিত হতে পারে। তখন অন্তত এগুলো দিন: 00-seo-router.md, 11-glossary.md, আর আপনার কাজের বিষয়ের ২–৩টা ফাইল (যেমন 02-keyword-research.md, 03-on-page-seo.md)।
  4. প্রজেক্টের ভেতরে নতুন চ্যাট খুলে প্রশ্ন করুন।

Gemini: Gem বানানো

  1. gemini.google.com-এ যান → বাঁ পাশে Gems (বা "Explore Gems") → New Gem।
  2. Name: SEO Assistant
  3. Instructions: chatgpt-files/00-instructions.md-এর --- লাইনের নিচের লেখা পেস্ট করুন। (এই নির্দেশনা Gemini-তেও একইভাবে কাজ করে।)
  4. Knowledge: "Add files" বা "+" চাপুন। gemini-files ফোল্ডারের ৯টা ফাইল আপলোড করুন। Gem-এ ফাইলের সংখ্যার সীমা থাকে, তাই এখানে আগে থেকে জোড়া দেওয়া ফাইল রাখা আছে।
  5. Save চাপুন, তারপর Gem খুলে প্রশ্ন করুন।

Gemini-তে Python স্ক্রিপ্ট সবসময় চলে না। তাই ট্রাফিক ড্রপ বিশ্লেষণে সেখানে "manual spreadsheet method" ব্যবহার হবে। Gem নিজেই ধাপগুলো বলে দেবে।

অন্য AI (NotebookLM, Perplexity Spaces, Copilot ইত্যাদি)

যে AI-তে ফাইল আপলোড আর নির্দেশনা দেওয়া যায়, সেখানে একই কাজ করবেন: 1. 00-instructions.md-এর লেখা নির্দেশনার ঘরে দিন। 2. chatgpt-files (বা ফাইল কম নিলে gemini-files) আপলোড করুন।

শুধু চ্যাট করা যায়, ফাইল দেওয়া যায় না, এমন AI হলে: প্রথম মেসেজে 00-instructions.md-এর লেখা পেস্ট করুন, তারপর যে বিষয়ে কাজ সেই ফাইলের দরকারি অংশ পেস্ট করে প্রশ্ন করুন।

ঠিকমতো কাজ করছে কিনা বুঝবেন কীভাবে

এই প্রশ্নটা করুন: keyword difficulty কী? সহজ করে বলো।

ঠিক থাকলে উত্তরে এসব থাকবে: - ✅ বাংলায় সহজ ব্যাখ্যা। - ✅ উত্তর প্লেবুক থেকে নেওয়া। যেমন বলবে নতুন সাইটের জন্য কম KD (প্রায় ২০-এর নিচে) বেছে নিতে। - ✅ শেষে কী করবেন তার ছোট তালিকা।

উত্তর একদম সাধারণ লাগলে লিখুন: knowledge ফাইল থেকে উত্তর দাও।

❌ SEO কীভাবে করব?

✅ আমি SEO-তে নতুন। আমার একটা অনলাইন শাড়ির দোকান আছে (Shopify-তে, ৩ মাস পুরনো, মাসে ২০০ ভিজিটর)। Google থেকে বিক্রি বাড়াতে চাই। শুধু ফ্রি টুল ব্যবহার করে ৩০ দিনের একটা কাজের তালিকা দাও।

একটা উদাহরণ কথোপকথন

আপনি:

আমার ঢাকায় একটা ডেন্টাল ক্লিনিক আছে। ওয়েবসাইট আছে কিন্তু Google-এ "dentist in dhanmondi" লিখলে আমাদের পাই না। কী করব? আমি টেকনিক্যাল না।

AI (সংক্ষেপে যা বলবে):

আপনার জন্য সবচেয়ে বড় সুযোগ হলো Google Business Profile (Google Maps-এ আপনার ব্যবসার তথ্য)। "dentist in dhanmondi" ধরনের সার্চে প্রথমে ম্যাপ দেখায়। এই সপ্তাহে ৫টা কাজ করুন: 1. Google Business Profile claim ও verify করুন… 2. Primary category দিন "Dentist"… 3. প্রতিটা রোগীর কাছে রিভিউ চান… … | কাজ | কেন | প্রভাব | সময় | |---|---|---|---|

আপনি (ফলো-আপ):

১ নম্বরটা কীভাবে করব? ধাপে ধাপে বলো।

AI তখন ধাপে ধাপে দেখিয়ে দেবে। যতবার দরকার ফলো-আপ প্রশ্ন করুন। এটাই সবচেয়ে কার্যকর উপায়।

কাজের জিনিস বানিয়ে নিন

AI শুধু পরামর্শ দেয় না, সরাসরি ব্যবহারযোগ্য জিনিসও বানায়: - Title ও meta description: "এই পেজের জন্য ৫টা title অপশন দাও, ৬০ অক্ষরের মধ্যে" - ব্লগের আউটলাইন: "'বাচ্চাদের জন্য স্বাস্থ্যকর টিফিন' বিষয়ে SEO-ফ্রেন্ডলি আউটলাইন বানাও" - Outreach ইমেইল: "অন্য ব্লগারকে guest post-এর প্রস্তাব দিয়ে ভদ্র একটা ইমেইল লেখো" - Schema কোড: "আমার রেস্টুরেন্টের জন্য LocalBusiness schema (JSON-LD) বানাও" - ক্লায়েন্ট রিপোর্ট: "এই ডেটা থেকে ক্লায়েন্টের জন্য মাসিক SEO রিপোর্ট লেখো"

ফাইল, ছবি বা লিংক দিন

  • স্ক্রিনশট: Search Console বা Analytics-এর গ্রাফের ছবি দিয়ে লিখুন "এটা দেখে বলো কী হচ্ছে"।
  • CSV বা Excel ফাইল: keyword-এর তালিকা দিয়ে লিখুন "এগুলো গ্রুপ করে দাও"।
  • পেজের লেখা: আপনার ব্লগ পোস্ট পেস্ট করে লিখুন "on-page SEO চেক করো"।
  • লিংক: যে AI ওয়েব ব্রাউজ করতে পারে, তাকে URL দিন।

২. Keyword রিসার্চ

  • 🟢 keyword কী? আমার [বিষয়] ব্লগের জন্য কীভাবে keyword খুঁজব? ফ্রি উপায়ে।
  • 🟢 [বিষয়] নিয়ে ২০টা long-tail keyword আইডিয়া দাও যেগুলোতে নতুন সাইট র‍্যাংক করতে পারে।
  • 🟢 "[keyword]" keyword-টা আমার জন্য ভালো কিনা কীভাবে বুঝব?
  • 🟡 এই keyword তালিকা [পেস্ট করুন] search intent অনুযায়ী ভাগ করো (informational/commercial/transactional), আর কোনটা দিয়ে শুরু করব বলো।
  • 🟡 আমার প্রোডাক্ট [বর্ণনা]। কেনার ইচ্ছা আছে এমন (buyer-intent) keyword খুঁজে বের করার পদ্ধতি আর ১৫টা উদাহরণ দাও।
  • 🟡 প্রতিযোগী কোন keyword-এ র‍্যাংক করছে কিন্তু আমি করছি না (keyword gap), সেটা কীভাবে বের করব?
  • 🟡 এই keyword-গুলো [পেস্ট] কোন পেজে কোনটা যাবে তার keyword map বানাও।
  • 🔴 আমার কাছে ৮,০০০ keyword আছে [CSV]। SERP overlap দিয়ে clustering আর URL mapping করার পুরো প্রক্রিয়া দাও।
  • 🔴 zero-volume keyword-গুলো কখন টার্গেট করা উচিত? আমার B2B সাইটের জন্য একটা স্কোরিং মডেল দাও।

১. মূল ধারণা: ৪ স্তরের সিস্টেম

  1. আপনার প্রশ্ন। যেকোনো ভাষায়, যেকোনো লেভেলে। সাথে ফাইল, স্ক্রিনশট বা ডেটাও দিতে পারেন।
  2. seo-router। প্রশ্ন বুঝে ঠিক করে কোন ভাষায় উত্তর দেবে, আপনি নতুন না অভিজ্ঞ, আর কোন বিশেষজ্ঞ skill লাগবে। কাজ বড় হলে কয়েকটা skill ধাপে ধাপে চালায় (workflow)।
  3. বিশেষজ্ঞ skill। ১০টা বিষয়ভিত্তিক skill। প্রতিটায় আছে শেখার পথ আর "Quick playbooks" টেবিল, যেটা দেখে AI ঠিক প্লেবুক খুঁজে নেয়।
  4. প্লেবুক ও টুল। ৫১৪টা প্লেবুক, প্রতিটা একই কাঠামোয় লেখা: সারাংশ, ধাপ, চেকলিস্ট, ডেটা, ভুল, মূলনীতি। সাথে আছে traffic-drop-doctor-এর অ্যানালাইসিস স্ক্রিপ্ট।

AI পুরো লাইব্রেরি একসাথে পড়ে না, শুধু দরকারি ১–৩টা প্লেবুক পড়ে। এতে উত্তর দ্রুত আসে আর ফোকাসড থাকে।

৪. অভিজ্ঞদের জন্য

Workflow চালান, একক প্রশ্ন নয়। router-এ ৭টা multi-skill workflow আছে। নাম ধরে চাইলে AI পুরো ক্রম মেনে কাজ করবে: - workflow B অনুযায়ী [সাইট]-এর পূর্ণ অডিট করো: technical → on-page → content → links → AI visibility, তারপর impact/effort অনুযায়ী সাজানো issue list দাও। - workflow E অনুযায়ী ৩ প্রতিযোগীর বিপরীতে AI visibility প্ল্যান দাও।
