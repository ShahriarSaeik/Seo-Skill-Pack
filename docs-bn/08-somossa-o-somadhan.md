# সমস্যা ও সমাধান (FAQ)

## ইনস্টলের সমস্যা

**প্রশ্ন: Claude-এ Skills অপশন খুঁজে পাচ্ছি না।**
- Settings → **Capabilities**-এ দেখুন। আগে **"Code execution and file creation"** চালু করতে হয়, তারপর Skills অংশ দেখা যায়।
- আপনার প্ল্যানে Skills ফিচার না থাকতে পারে। তখন [02-install-claude.md](02-install-claude.md)-এর **পদ্ধতি খ** (Project) ব্যবহার করুন।

**প্রশ্ন: `.skill` ফাইল আপলোড হচ্ছে না, "unsupported file" দেখাচ্ছে।**
- ফাইলের নামের শেষ `.skill` বদলে `.zip` করে আবার চেষ্টা করুন।
- Windows-এ ফাইলের extension দেখা না গেলে: File Explorer → **View** → **File name extensions** টিক দিন।

**প্রশ্ন: ChatGPT-তে Custom GPT বানানোর অপশন নেই।**
- Custom GPT বানাতে সাধারণত পেইড প্ল্যান লাগে। ফ্রি হলে **Projects** ব্যবহার করুন ([03-install-chatgpt-gemini.md](03-install-chatgpt-gemini.md))।

**প্রশ্ন: সব ফাইল আপলোড করতে দিচ্ছে না (ফাইল সংখ্যার সীমা)।**
- সবসময় রাখবেন `00-seo-router.md` আর `11-glossary.md`, সাথে আপনার কাজের বিষয়ের ২–৪টা ফাইল।
- Gemini-তে `gemini-files` ফোল্ডার ব্যবহার করুন। সেখানে ফাইল কম, কারণ কয়েকটা জোড়া দেওয়া।

**প্রশ্ন: Windows-এ PowerShell স্ক্রিপ্ট চলছে না ("running scripts is disabled")।**
- PowerShell খুলে এটা চালান:
  `powershell -ExecutionPolicy Bypass -File install-claude-code.ps1`
- অথবা হাতে কপি করুন: `3-coding-agents\skills\`-এর ভেতরের ফোল্ডারগুলো `C:\Users\আপনার-নাম\.claude\skills\`-এ রাখুন।

## ব্যবহারের সমস্যা

**প্রশ্ন: AI skill ব্যবহার করছে কিনা কীভাবে বুঝব?**
- উত্তরের শেষে কাজের তালিকা বা টেবিল থাকে, আর ব্যাখ্যা প্লেবুকের মতো গোছানো হয়।
- নিশ্চিত হতে চাইলে জিজ্ঞেস করুন: `তুমি কোন skill বা প্লেবুক ব্যবহার করলে?`
- Claude-এ ব্যবহার না করলে স্পষ্ট করে বলুন: `seo-router skill ব্যবহার করে উত্তর দাও।`

**প্রশ্ন: উত্তর ইংরেজিতে আসছে।**
- লিখুন: `বাংলায় উত্তর দাও।` এরপর থেকে বাংলাতেই উত্তর দেবে। নতুন চ্যাটে প্রথম প্রশ্ন বাংলায় করলে সাধারণত শুরু থেকেই বাংলায় আসে।

**প্রশ্ন: উত্তর অনেক কঠিন বা অনেক লম্বা।**
- লিখুন: `আমি নতুন, আরও সহজ করে ৫টা পয়েন্টে বলো।`

**প্রশ্ন: উত্তর খুব সাধারণ লাগছে, আমার সাইটের সাথে মিলছে না।**
- নিজের তথ্য দিন: সাইটের ধরন, দেশ, বয়স, ট্রাফিক, লক্ষ্য ([05-prothom-babohar.md](05-prothom-babohar.md) দেখুন)।

**প্রশ্ন: AI একটা সংখ্যা বা পরিসংখ্যান বলল, এটা কি ঠিক?**
- প্লেবুকের পরিসংখ্যান ২০২৬ সাল পর্যন্ত বিভিন্ন গবেষণা থেকে নেওয়া। গুরুত্বপূর্ণ কাজে (যেমন ক্লায়েন্ট রিপোর্টে) ব্যবহারের আগে যাচাই করুন। AI-কে বলতে পারেন: `এই তথ্যটা ওয়েবে যাচাই করো।`

**প্রশ্ন: Traffic Drop Doctor "No usable data" বলছে।**
- Compare export দিয়েছেন কিনা দেখুন। Date ফিল্টারের **Compare** ট্যাব থেকে export করতে হয়।
- zip ফাইলটা খুলে ভেতরের ফাইল আলাদা করে দিলে সমস্যা হতে পারে। পুরো zip দিন।
- Clicks, Impressions, CTR, Position চারটা বক্সই চালু করে export করতে হয়।

**প্রশ্ন: স্ক্রিপ্ট বলছে ডেটা পুরনো ("data ends … days ago")।**
- Search Console থেকে আজকের তারিখ পর্যন্ত নতুন করে export করুন।

## অন্যান্য

**প্রশ্ন: এগুলো কি পেইড টুল (যেমন keyword টুল) ছাড়া কাজ করে?**
- হ্যাঁ। প্রতিটা কাজের জন্য ফ্রি বিকল্প বলে দেয়: Google Search Console, Google autocomplete, People Also Ask, PageSpeed Insights, Keyword Planner।

**প্রশ্ন: আমার ওয়েবসাইটের তথ্য কি অন্য কেউ দেখবে?**
- Skill ফাইলগুলো শুধু নির্দেশনা আর প্লেবুক, এগুলো আপনার ডেটা কোথাও পাঠায় না। আপনি যে AI-তে ডেটা আপলোড করেন, সেই প্ল্যাটফর্মের প্রাইভেসি নীতি প্রযোজ্য হবে।

**প্রশ্ন: নতুন ভার্সন এলে কীভাবে আপডেট করব?**
- পুরনো skill বা ফাইল মুছে নতুনগুলো একইভাবে আপলোড করুন। Claude Code-এ ইনস্টল স্ক্রিপ্ট আবার চালালেই হবে।
