# SEO শব্দকোষ (সহজ বাংলায়)

AI-এর উত্তরে বা প্লেবুকে এই শব্দগুলো বারবার আসবে। সম্পূর্ণ ইংরেজি তালিকা আছে প্রতিটা skill-এর `GLOSSARY.md`-এ।

## মৌলিক
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **SEO** | Google-এর ফ্রি ফলাফলে (বিজ্ঞাপন ছাড়া) আপনার সাইটকে উপরে আনার কাজ |
| **Organic traffic** | Google সার্চ থেকে ফ্রিতে আসা ভিজিটর |
| **SERP** | Google-এ কিছু লিখে সার্চ করলে যে ফলাফলের পেজ আসে |
| **Ranking / Position** | সার্চ ফলাফলে আপনার পেজ কত নম্বরে আছে |
| **Crawl** | Google-এর রোবট (Googlebot) আপনার পেজ পড়তে আসা |
| **Index** | Google আপনার পেজ নিজের তালিকায় যোগ করা। index না হলে সার্চে আসবে না |
| **Algorithm update** | Google-এর র‍্যাংকিং নিয়মে পরিবর্তন |
| **E-E-A-T** | অভিজ্ঞতা, দক্ষতা, কর্তৃত্ব, বিশ্বাসযোগ্যতা: Google কনটেন্টের মান যাচাই করে এগুলো দিয়ে |

## Keyword
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **Keyword** | মানুষ Google-এ যে শব্দ বা বাক্য লিখে সার্চ করে |
| **Search volume** | মাসে কতবার একটা keyword সার্চ হয় |
| **Keyword difficulty (KD)** | ওই keyword-এ র‍্যাংক করা কতটা কঠিন (০–১০০) |
| **Long-tail keyword** | লম্বা ও নির্দিষ্ট সার্চ, যেমন "ঢাকায় বাচ্চাদের দাঁতের ডাক্তার"। সার্চ কম, কিন্তু র‍্যাংক করা সহজ |
| **Search intent** | মানুষ কেন সার্চ করছে: জানতে, কিনতে, তুলনা করতে, নাকি কোনো সাইটে যেতে |
| **Cannibalization** | একই keyword-এর জন্য আপনার একাধিক পেজ নিজেদের মধ্যে প্রতিযোগিতা করা |

## পেজ (On-page)
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **Title tag** | Google ফলাফলে নীল রঙের যে শিরোনাম দেখায় |
| **Meta description** | শিরোনামের নিচের ছোট বর্ণনা |
| **H1, H2** | পেজের ভেতরের শিরোনাম ও উপ-শিরোনাম |
| **Slug / URL** | পেজের ঠিকানার শেষ অংশ, যেমন `/keyword-research/` |
| **Alt text** | ছবির লিখিত বর্ণনা (দৃষ্টিপ্রতিবন্ধী আর Google দুজনের জন্যই) |
| **Schema** | বিশেষ কোড, যা Google-কে পেজের তথ্য বুঝতে সাহায্য করে (দাম, রেটিং, ঠিকানা) |
| **Internal link** | আপনার সাইটের এক পেজ থেকে আরেক পেজে লিংক |
| **CTR** | যতবার দেখানো হয়েছে, তার মধ্যে কত শতাংশ মানুষ ক্লিক করেছে |
| **Impressions** | Google-এ আপনার পেজ কতবার দেখানো হয়েছে |

## লিংক
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **Backlink** | অন্য সাইট থেকে আপনার সাইটে আসা লিংক। ভালো সাইটের লিংক মানে "ভোট" |
| **Referring domains** | কতগুলো আলাদা সাইট আপনাকে লিংক দিয়েছে |
| **Anchor text** | লিংকের ক্লিক করা যায় এমন লেখা |
| **Nofollow** | এমন লিংক, যা Google-কে "ভোট" হিসেবে না গুনতে বলে |
| **DR / DA** | বিভিন্ন টুলের দেওয়া সাইটের "শক্তি"র স্কোর (০–১০০)। Google নিজে এটা ব্যবহার করে না |
| **Outreach** | লিংক বা সহযোগিতার জন্য অন্য সাইটের মালিককে ইমেইল করা |
| **Disavow** | Google-কে বলা যে নির্দিষ্ট খারাপ লিংক গোনায় ধরবে না (শুধু বিশেষ ক্ষেত্রে) |

## টেকনিক্যাল
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **robots.txt** | ফাইল, যেটা Google-কে বলে সাইটের কোন অংশে ঢুকবে না |
| **Sitemap** | সাইটের সব গুরুত্বপূর্ণ পেজের তালিকা, Google-এর জন্য |
| **noindex** | পেজে এমন নির্দেশ, যার জন্য Google ওই পেজ সার্চে দেখায় না |
| **Canonical tag** | একই রকম কয়েকটা পেজের মধ্যে কোনটা "আসল", তা Google-কে জানানো |
| **301 redirect** | পুরনো URL থেকে নতুন URL-এ স্থায়ীভাবে পাঠানো |
| **404** | পেজ পাওয়া যায়নি |
| **Core Web Vitals** | সাইটের গতি ও ব্যবহার-অভিজ্ঞতার মাপ: LCP (লোড), INP (সাড়া দেওয়া), CLS (স্থিরতা) |
| **Migration** | সাইটের ডোমেইন, URL বা প্ল্যাটফর্ম বদলানো |

## লোকাল
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **Google Business Profile (GBP)** | Google Maps-এ আপনার ব্যবসার ফ্রি প্রোফাইল |
| **Local pack / Map pack** | লোকাল সার্চে ম্যাপসহ ৩টা ব্যবসার তালিকা |
| **NAP** | Name, Address, Phone: সব জায়গায় হুবহু একই রাখতে হয় |
| **Citation** | অন্য ওয়েবসাইট বা ডিরেক্টরিতে আপনার ব্যবসার নাম-ঠিকানা-ফোন |

## AI সার্চ
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **AI Overviews** | Google ফলাফলের উপরে AI-এর লেখা সারাংশ |
| **AEO / GEO** | ChatGPT বা Google AI-এর উত্তরে নিজের ব্র্যান্ড আনার কৌশল |
| **Citation (AI)** | AI-এর উত্তরে আপনার সাইটের লিংক উৎস হিসেবে দেখানো |
| **Zero-click search** | Google-এই উত্তর পেয়ে যাওয়ায় কেউ কোনো সাইটে ক্লিক না করা |
| **Query fan-out** | AI একটা প্রশ্নকে ছোট ছোট অনেক সার্চে ভাগ করে খোঁজে |

## ট্রাফিক বিশ্লেষণ
| শব্দ | সহজ বাংলায় মানে |
|---|---|
| **Search Console** | Google-এর ফ্রি টুল। আপনার সাইট সার্চে কেমন করছে দেখায় |
| **Brand / Non-brand** | আপনার ব্র্যান্ডের নাম দিয়ে সার্চ বনাম সাধারণ সার্চ |
| **Seasonality** | বছরের নির্দিষ্ট সময়ে সার্চ এমনিতেই বাড়া-কমা |
| **Manual action** | মানুষ পর্যালোচকের দেওয়া Google-এর শাস্তি |
| **YoY (Year over Year)** | গত বছরের একই সময়ের সাথে তুলনা |
