# Traffic Drop Doctor: ট্রাফিক কমে গেলে কী করবেন

সাইটের ট্রাফিক হঠাৎ কমে গেলে এই skill আপনার Google Search Console-এর ডেটা বিশ্লেষণ করে। তারপর জানায়:
- **কেন কমেছে।** কারণগুলো গুরুত্ব অনুযায়ী সাজানো থাকে, প্রতিটার সাথে কতটা নিশ্চিত আর কী প্রমাণ।
- **কোন কারণ কতটা দায়ী।** যেমন ৫০% র‍্যাংকিং কমার জন্য, ৩০% AI Overviews-এর জন্য।
- **কোনটা ঠিক করা যাবে, কোনটা যাবে না।**
- **কী করতে হবে।** অগ্রাধিকার অনুযায়ী সাজানো কাজের তালিকা।
- **ক্লায়েন্টকে পাঠানোর মতো রিপোর্ট**, গ্রাফ সহ।

## এটা যে কারণগুলো ধরতে পারে
| কারণ | সহজ ভাষায় |
|---|---|
| ট্র্যাকিং বা ডেটার সমস্যা | আসলে ট্রাফিক কমেনি, মাপার যন্ত্রে গোলমাল |
| ইনডেক্সিং বা টেকনিক্যাল সমস্যা | কিছু পেজ Google থেকে বাদ পড়েছে (যেমন ভুল করে `noindex` বসানো) |
| সাইট migration বা redesign | URL বদলেছে কিন্তু redirect ঠিকমতো দেওয়া হয়নি |
| Google algorithm update | Google-এর নিয়ম বদলেছে, র‍্যাংকিং পড়ে গেছে |
| AI Overviews বা SERP পরিবর্তন | র‍্যাংকিং ঠিক আছে, কিন্তু Google-এ AI-এর উত্তর দেখে মানুষ কম ক্লিক করছে |
| প্রতিযোগী বা পুরনো কনটেন্ট | অন্য সাইট আরও ভালো কনটেন্ট দিয়েছে |
| মৌসুমি পরিবর্তন | প্রতি বছর এই সময়ে এমনিতেই সার্চ কমে |
| ব্র্যান্ডের চাহিদা কমা | মানুষ আপনার ব্র্যান্ডের নাম কম সার্চ করছে (এটা SEO-র সমস্যা নয়) |
| Manual action | Google শাস্তি দিয়েছে। এটা ডেটায় দেখা যায় না, তাই হাতে চেক করতে হয় |

---

> **আগে যা লাগবে:** আপনার সাইট Google Search Console-এ যুক্ত থাকতে হবে (Google-এর ফ্রি টুল, যেখানে সাইটের সার্চ ডেটা জমা হয়)। যুক্ত না থাকলে AI-কে লিখুন `Google Search Console কীভাবে সেটআপ করব? ধাপে ধাপে বলো।` মনে রাখবেন, সেটআপের পর থেকে ডেটা জমা হতে শুরু করে, আগের ডেটা পাওয়া যায় না। অচেনা শব্দের মানে পাবেন [09-shobdokosh.md](09-shobdokosh.md)-এ।

## ধাপ ১: Search Console থেকে ডেটা ডাউনলোড (৫ মিনিট)

### ফাইল ১: তুলনার ডেটা (Compare export), এটা অবশ্যই লাগবে
1. [search.google.com/search-console](https://search.google.com/search-console)-এ যান, আপনার সাইট বেছে নিন।
2. বাঁ পাশে **Performance** (বা "Search results")-এ ক্লিক করুন।
3. উপরের চারটা বক্স **Total clicks, Total impressions, Average CTR, Average position** চারটাই ক্লিক করে চালু করুন (রঙিন হবে)।
4. **Date** ফিল্টারে ক্লিক করুন → **Compare** ট্যাব → নিচের যেকোনো একটা বেছে নিন:
   - **"Compare last 28 days to previous period"**, যদি সম্প্রতি কমে থাকে।
   - **Custom**: কমার আগের ৪ সপ্তাহ বনাম পরের ৪ সপ্তাহ। তারিখ জানা থাকলে এটাই সবচেয়ে ভালো।
5. **Apply** চাপুন → উপরে ডানে **Export** → **Download CSV**।
6. একটা `.zip` ফাইল ডাউনলোড হবে। **এটা খুলবেন না, যেমন আছে তেমনই রাখুন।**

### ফাইল ২: দৈনিক ডেটা (Dates.csv), থাকলে বিশ্লেষণ অনেক ভালো হয়
1. আবার **Date** ফিল্টার → **Filter** ট্যাব (Compare নয়) → **Last 16 months** → Apply।
2. **Export** → **Download CSV**।
3. ডাউনলোড হওয়া zip খুলে শুধু **`Dates.csv`** ফাইলটা আলাদা করে রাখুন।

### ঐচ্ছিক: সাইটে কী পরিবর্তন হয়েছিল, তার তালিকা
সাইটে কোনো পরিবর্তন করে থাকলে (নতুন ডিজাইন, URL বদল, প্লাগইন আপডেট), তারিখ সহ AI-কে লিখে জানান। যেমন: `১২ সেপ্টেম্বর সাইট নতুন থিমে নিয়েছি।`

## ধাপ ২: AI-কে দিন

### Claude (skill ইনস্টল থাকলে)
নতুন চ্যাটে দুটো ফাইল সংযুক্ত (attach) করুন। এর জন্য মেসেজ বক্সের পাশের 📎 বা **+** চিহ্নে ক্লিক করে ফাইল বেছে নিন। তারপর লিখুন:
```
আমার সাইটের ট্রাফিক কমে গেছে। সংযুক্ত Search Console ফাইলগুলো বিশ্লেষণ করে কারণ বের করো আর রিপোর্ট দাও।
সাইট: [example.com], ব্র্যান্ড নাম: [ব্র্যান্ড]।
সাম্প্রতিক পরিবর্তন: [থাকলে লিখুন, না থাকলে "জানা নেই"]।
```
Claude নিজেই স্ক্রিপ্ট চালিয়ে বিশ্লেষণ করবে।

### ChatGPT (Code Interpreter চালু থাকলে)
একই মেসেজ পাঠান। GPT knowledge-এ রাখা `12-analyze_gsc.py` স্ক্রিপ্ট চালাবে। না চালালে লিখুন: `knowledge-এর analyze_gsc.py স্ক্রিপ্ট দিয়ে এই ফাইল বিশ্লেষণ করো।`

### যেখানে কোড চলে না (Gemini বা অন্য AI)
AI হাতে হাতে বা স্প্রেডশিট দিয়ে বিশ্লেষণ করার ধাপ দেখাবে। একটু বেশি সময় লাগবে, কিন্তু পদ্ধতি একই।

### নিজে কম্পিউটারে চালাতে চাইলে (অভিজ্ঞদের জন্য)
Python 3 ইনস্টল থাকলে `3-coding-agents/skills/traffic-drop-doctor/scripts/` ফোল্ডারে টার্মিনাল খুলুন। আপনার ডাউনলোড করা ফাইল দুটো এই ফোল্ডারে কপি করে নিন, তারপর লিখুন:
```
python analyze_gsc.py --export compare.zip --dates Dates.csv --brand "আপনার-ব্র্যান্ড" --out report
```
ফলাফল আসবে `report` ফোল্ডারে: `report.md`, `timeline.png`, আর CSV ফাইলগুলো।

## ধাপ ৩: রিপোর্ট পড়ুন
রিপোর্টে যা থাকবে:
1. **সারাংশ:** কত কমেছে, কবে থেকে, আর গত বছরের একই সময়ের সাথে তুলনা।
2. **সম্ভাব্য কারণ:** গুরুত্ব অনুযায়ী সাজানো, প্রতিটার পাশে confidence লেখা থাকে: High (অনেক নিশ্চিত), Medium (মোটামুটি), Low (কম)।
3. **কাজের তালিকা:** কোনটা আগে করবেন।
4. **যা ডেটায় দেখা যায় না:** যেমন manual action। এগুলো নিজে চেক করতে হবে।

### উদাহরণ দেখতে চান?
প্যাকের `3-coding-agents/skills/traffic-drop-doctor/examples/example-report/` ফোল্ডারে একটা কাল্পনিক সাইটের পুরো রিপোর্ট আছে। `client-report.md` খুলে দেখুন চূড়ান্ত রিপোর্ট দেখতে কেমন হয়। Claude বা ChatGPT-তে AI-কে লিখেও দেখতে পারেন: `traffic-drop-doctor-এর উদাহরণ রিপোর্টটা দেখাও।`

## গুরুত্বপূর্ণ কথা
- **Google update চলাকালীন সাইটে বড় পরিবর্তন করবেন না।** update শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
- **সবার আগে Manual action চেক করুন** (৩০ সেকেন্ড লাগে): Search Console → **Security & Manual Actions** → **Manual actions**। "No issues detected" দেখলে নিশ্চিন্ত থাকুন।
- এই বিশ্লেষণ প্রমাণভিত্তিক, কিন্তু ১০০% নিশ্চিত নয়। তাই রিপোর্টে প্রতিটা কারণ কীভাবে যাচাই করবেন তাও লেখা থাকে।
- পুরনো ডেটা দিলে স্ক্রিপ্ট সতর্ক করবে। সবসময় সর্বশেষ ডেটা দিন।
- সাইট বড় হলে (১,০০০-এর বেশি পেজ) Search Console থেকে সব ডেটা একবারে নামে না। তখন section ধরে আলাদা আলাদা export করুন।
