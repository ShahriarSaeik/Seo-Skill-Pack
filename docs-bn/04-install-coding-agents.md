# কোডিং AI টুলে সেটআপ (Claude Code, Cursor, Copilot, Codex, Gemini CLI)

ওয়েবসাইটের কোড নিয়ে যারা কাজ করেন (ডেভেলপার বা টেকনিক্যাল SEO), তাদের জন্য এই পদ্ধতি। এতে AI সরাসরি আপনার সাইটের কোড দেখে SEO ঠিক করতে পারে, যেমন meta tag বসানো বা schema যোগ করা।

**যা লাগবে:** প্যাকের `3-coding-agents` ফোল্ডার। এতে আছে:
```
3-coding-agents/
├── AGENTS.md      ← AI-কে কোথায় কী আছে তা জানায়
├── GLOSSARY.md
└── skills/        ← ১১টা skill
```

## সবচেয়ে সহজ উপায় (সব টুলে চলে)
`3-coding-agents` ফোল্ডারের **ভেতরের তিনটা জিনিস** (`AGENTS.md`, `GLOSSARY.md`, `skills`) কপি করে আপনার ওয়েবসাইট প্রজেক্টের মূল ফোল্ডারে (root) রাখুন। Root মানে প্রজেক্টের সবচেয়ে বাইরের ফোল্ডার, যেটা আপনি Cursor বা VS Code-এ খোলেন। অনেক টুল `AGENTS.md` নিজে থেকেই পড়ে।

## টুল অনুযায়ী
| টুল | কী করবেন |
|---|---|
| **Claude Code** | `install` ফোল্ডারের স্ক্রিপ্ট চালান (নিয়ম আছে [02-install-claude.md](02-install-claude.md)-এর পদ্ধতি গ-তে)। Skill-গুলো সব প্রজেক্টে কাজ করবে। |
| **Cursor** | উপরের "সবচেয়ে সহজ উপায়" অনুসরণ করুন। Cursor প্রজেক্টের root-এ রাখা `AGENTS.md` পড়ে। |
| **GitHub Copilot (VS Code)** | একইভাবে root-এ রাখুন। `AGENTS.md` না পড়লে এর লেখাটা `.github/copilot-instructions.md` ফাইলে কপি করে দিন। |
| **OpenAI Codex CLI** | Root-এ রাখুন (Codex `AGENTS.md` পড়ে)। নতুন ভার্সনে `skills` ফোল্ডারের ভেতরের ফোল্ডারগুলো `~/.codex/skills/`-এও রাখতে পারেন। |
| **Gemini CLI** | Root-এ রাখুন। তারপর `AGENTS.md` ফাইলের একটা কপি বানিয়ে নাম দিন `GEMINI.md`। |
| **Windsurf, Zed, Aider, অন্যান্য** | Root-এ রাখুন। প্রথম মেসেজে লিখুন: `AGENTS.md পড়ে সেই অনুযায়ী কাজ করো।` |

## পরীক্ষা
প্রজেক্ট খুলে AI-কে বলুন:
```
এই সাইটের হোমপেজের title, meta description আর heading চেক করো। on-page-seo skill অনুযায়ী কী ঠিক করতে হবে তা বলো, তারপর ঠিক করে দাও।
```

> ⚠️ কোডিং AI আপনার ফাইল বদলে দিতে পারে। বড় কোনো পরিবর্তনের আগে ব্যাকআপ রাখুন (git ব্যবহার করলে commit করে নিন; না করলে প্রজেক্ট ফোল্ডারের একটা কপি রাখুন)। লাইভ সাইটে দেওয়ার আগে পরীক্ষা করে নিন।
