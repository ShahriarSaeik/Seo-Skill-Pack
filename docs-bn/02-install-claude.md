| claude.ai-তে Skills অপশন খুঁজে পাচ্ছেন না | **পদ্ধতি খ** (Project ব্যবহার করে) |

## পদ্ধতি ক: claude.ai বা Desktop অ্যাপে Skill আপলোড

> ℹ️ Claude-এর মেনু আর বাটনের নাম মাঝে মাঝে বদলায়। নিচের নামের সাথে হুবহু না মিললে চিন্তা করবেন না, কাছাকাছি নামের অপশন খুঁজুন। Skills ফিচার কোন প্ল্যানে আছে তাও বদলাতে পারে। Skills অপশন না পেলে **পদ্ধতি খ** ব্যবহার করুন।

**যা লাগবে:** প্যাকের `1-Claude` ফোল্ডার, যেখানে ১১টা `.skill` ফাইল আছে।

### ধাপ ১: কোড চালানোর অনুমতি চালু করুন
1. claude.ai-তে লগইন করুন।
2. নিচে বাঁ দিকে আপনার নামে ক্লিক করুন → **Settings**।
3. **Capabilities** ট্যাবে যান।
4. **"Code execution and file creation"** সুইচটা চালু (ON) করুন। Skill চলার জন্য এটা দরকার।

### ধাপ ২: Skill আপলোড করুন
1. একই **Capabilities** পেজে নিচে **Skills** অংশ পাবেন।
2. **"Upload skill"** বাটনে ক্লিক করুন।
3. `1-Claude` ফোল্ডার থেকে প্রথমে **`seo-router.skill`** বেছে নিন।
4. বাকি ১০টা ফাইলও একইভাবে একটা একটা করে আপলোড করুন।
5. আপলোডের পর প্রতিটা skill-এর পাশের সুইচ চালু (ON) আছে কিনা দেখে নিন।

> 💡 **`.skill` ফাইল আপলোড না নিলে** ফাইলের নামের শেষের `.skill` বদলে `.zip` করে দিন (যেমন `seo-router.zip`), তারপর আবার আপলোড করুন। দুটো আসলে একই ফাইল।

> 💡 **সব skill লাগবে না?** নতুনদের জন্য ন্যূনতম সেট: `seo-router`, `seo-fundamentals`, `keyword-research`, `on-page-seo`। লোকাল বিজনেস হলে সাথে `local-seo` দিন।

### ধাপ ৩: পরীক্ষা করুন
একটা নতুন চ্যাট খুলে লিখুন:
```
আমার নতুন ওয়েবসাইট Google-এ কীভাবে আনব? আমি একদম নতুন।
```
উত্তর লেখার সময় Claude যদি skill পড়ে (স্ক্রিনে "Reading skill…" বা এমন কিছু দেখাতে পারে) আর লেভেল অনুযায়ী ধাপে ধাপে প্ল্যান দেয়, তাহলে সব ঠিক আছে ✅

**অন্য উপায়:** কোনো চ্যাটে কেউ `.skill` ফাইল পাঠালে ফাইলের কার্ডে **"Save skill"** বাটন দেখা যেতে পারে। সেখানে ক্লিক করলেও ইনস্টল হয়ে যায়।

## পদ্ধতি খ: Claude Project ব্যবহার করে (Skills অপশন না থাকলে)
1. claude.ai-তে বাঁ পাশের মেনু থেকে **Projects** → **Create project**। নাম দিন, যেমন "SEO Assistant"।
2. প্রজেক্টের **Instructions** (বা "Set project instructions") ঘরে `2-ChatGPT-Gemini/chatgpt-files/00-instructions.md` ফাইল খুলুন। সেখানে `---` (তিনটা হাইফেন) দিয়ে একটা লাইন আছে। **ওই লাইনের নিচের সব লেখা** কপি করে এখানে পেস্ট করুন।
3. **Project knowledge**-এ ফাইল যোগ করুন। `2-ChatGPT-Gemini/chatgpt-files` ফোল্ডারের সব ফাইল দিন, বা যেগুলো দরকার সেগুলো। সবসময় রাখবেন `00-seo-router.md` আর `11-glossary.md`।
4. এখন ওই প্রজেক্টের ভেতরে নতুন চ্যাট খুলে প্রশ্ন করুন।

## পদ্ধতি গ: Claude Code-এ ইনস্টল (এক ক্লিকে)

> আগে থেকে Claude Code ইনস্টল থাকতে হবে। টার্মিনাল হলো কম্পিউটারে লিখে কমান্ড দেওয়ার প্রোগ্রাম (Mac-এ "Terminal", Windows-এ "PowerShell")।

### Mac বা Linux
1. Finder-এ প্যাকের `install` ফোল্ডারে রাইট-ক্লিক করুন → **"New Terminal at Folder"**। এতে টার্মিনাল ওই ফোল্ডারের ভেতরেই খুলবে। (অপশনটা না দেখালে: System Settings → Keyboard → Keyboard Shortcuts → Services থেকে চালু করুন, অথবা টার্মিনালে `cd ` লিখে ফোল্ডারটা টেনে এনে ছেড়ে দিন, তারপর Enter চাপুন।)
2. টার্মিনালে লিখুন:
   ```
   bash install-claude-code.sh
   ```
3. "Done: 11 skills installed" লেখা দেখলে Claude Code বন্ধ করে আবার চালু করুন।

### Windows
1. `install` ফোল্ডারে `install-claude-code.ps1` ফাইলে রাইট-ক্লিক করুন → **"Run with PowerShell"**।
2. "Done" দেখলে Enter চাপুন, তারপর Claude Code রিস্টার্ট করুন।

> শুধু একটা প্রজেক্টের জন্য ইনস্টল করতে চাইলে স্ক্রিপ্টের শেষে প্রজেক্টের ফোল্ডারের পাথ দিন, যেমন `bash install-claude-code.sh ~/my-website`।

**হাতে কপি করতে চাইলে:** `3-coding-agents/skills/` ফোল্ডারের ভেতরের ১১টা ফোল্ডার কপি করে আপনার হোম ফোল্ডারের `.claude/skills/` ফোল্ডারে রাখুন। Mac-এ এটা `/Users/আপনার-নাম/.claude/skills/` (সংক্ষেপে `~/.claude/skills/`), Windows-এ `C:\Users\আপনার-নাম\.claude\skills\`। `.claude` লুকানো ফোল্ডার: Mac-এ Finder-এ `Cmd + Shift + .` চাপলে দেখা যায়।

## আপডেট বা মুছে ফেলা
- **আপডেট:** নতুন ভার্সন পেলে আগের skill মুছে নতুনটা আপলোড করুন। Claude Code-এ শুধু ইনস্টল স্ক্রিপ্ট আবার চালালেই হয়।
- **বন্ধ রাখা বা মুছে ফেলা:** Settings → Capabilities → Skills থেকে সুইচ বন্ধ করুন বা মুছে দিন।
