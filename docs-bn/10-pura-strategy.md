# পুরো স্ট্র্যাটেজি: সিস্টেম কীভাবে কাজ করে আর কীভাবে সবচেয়ে ভালো ফল পাবেন

এই গাইড পড়লে বুঝবেন প্যাকটা ভেতরে কীভাবে সাজানো, কোন সমস্যায় কোন skill লাগে, আর আপনার লেভেল অনুযায়ী কোন পথে এগোবেন। নতুনরা প্রথম তিনটা অংশ পড়লেই যথেষ্ট। অভিজ্ঞরা সরাসরি "অভিজ্ঞদের জন্য" অংশে চলে যান।

![সিস্টেম ম্যাপ](system-map.svg)

## ১. মূল ধারণা: ৪ স্তরের সিস্টেম
1. **আপনার প্রশ্ন।** যেকোনো ভাষায়, যেকোনো লেভেলে। সাথে ফাইল, স্ক্রিনশট বা ডেটাও দিতে পারেন।
2. **seo-router।** প্রশ্ন বুঝে ঠিক করে কোন ভাষায় উত্তর দেবে, আপনি নতুন না অভিজ্ঞ, আর কোন বিশেষজ্ঞ skill লাগবে। কাজ বড় হলে কয়েকটা skill ধাপে ধাপে চালায় (workflow)।
3. **বিশেষজ্ঞ skill।** ১০টা বিষয়ভিত্তিক skill। প্রতিটায় আছে শেখার পথ আর "Quick playbooks" টেবিল, যেটা দেখে AI ঠিক প্লেবুক খুঁজে নেয়।
4. **প্লেবুক ও টুল।** ৫১৪টা প্লেবুক, প্রতিটা একই কাঠামোয় লেখা: সারাংশ, ধাপ, চেকলিস্ট, ডেটা, ভুল, মূলনীতি। সাথে আছে `traffic-drop-doctor`-এর অ্যানালাইসিস স্ক্রিপ্ট।

AI পুরো লাইব্রেরি একসাথে পড়ে না, শুধু দরকারি ১–৩টা প্লেবুক পড়ে। এতে উত্তর দ্রুত আসে আর ফোকাসড থাকে।

## ২. সমস্যা অনুযায়ী কোন skill
| আপনার সমস্যা | কোন skill কাজ করবে | প্রথম প্রশ্ন হিসেবে লিখুন |
|---|---|---|
| নতুন সাইট, কোথা থেকে শুরু করব বুঝছি না | seo-router (workflow A) | `নতুন সাইটের জন্য ৩০ দিনের SEO প্ল্যান দাও` |
| সাইট Google-এ আসছেই না | technical-seo | `আমার সাইট Google-এ আসছে না কেন? ধাপে ধাপে চেক করাও` |
| কী নিয়ে লিখব বুঝছি না | keyword-research | `[বিষয়] নিয়ে কম প্রতিযোগিতার ২০টা keyword দাও` |
| পেজ আছে কিন্তু র‍্যাংক করছে না | on-page-seo | `এই পেজটা on-page SEO অনুযায়ী চেক করো: [লেখা/URL]` |
| দোকান বা অফিস Google Maps-এ নেই | local-seo | `আমার [ব্যবসা] Google Maps-এ দেখাচ্ছে না, কী করব?` |
| backlink দরকার | link-building | `লিংক না কিনে প্রথম ১০টা backlink কীভাবে পাব?` |
| কনটেন্ট প্ল্যান দরকার | content-marketing | `৩ মাসের কনটেন্ট ক্যালেন্ডার বানাও` |
| ট্রাফিক হঠাৎ কমে গেছে | traffic-drop-doctor | `ট্রাফিক ৪০% কমেছে, কারণ বের করো` + Search Console ফাইল |
| ChatGPT বা AI-এ ব্র্যান্ড দেখাতে চাই | ai-search | `ChatGPT-এ আমার ব্র্যান্ড আনার প্ল্যান দাও` |
| Schema বা structured data | seo-fundamentals | `আমার প্রোডাক্ট পেজের জন্য JSON-LD schema বানাও` |
| বস বা ক্লায়েন্টকে রিপোর্ট আর বাজেট দেখাতে হবে | enterprise-seo | `৩টা সিনারিও সহ SEO forecast বানাও` |

## ৩. নতুনদের জন্য ৩০ দিনের পথ
প্রতি সপ্তাহে ২–৩ ঘণ্টা দিলেই হবে। প্রতিটা ধাপের প্রম্পট কপি করে AI-কে দিন।

**সপ্তাহ ১: ভিত্তি**
- [ ] `Google Search Console কীভাবে সেটআপ করব? ধাপে ধাপে বলো।`
- [ ] `আমার সাইট Google-এ index হয়েছে কিনা কীভাবে চেক করব?`
- [ ] লোকাল ব্যবসা হলে: `Google Business Profile ধাপে ধাপে সেটআপ করাও।`

**সপ্তাহ ২: keyword**
- [ ] `আমার [ব্যবসা/বিষয়] এর জন্য ফ্রি টুল দিয়ে ২০টা keyword খুঁজে দাও, বাংলা আর ইংরেজি দুইভাবেই।`
- [ ] `এগুলো কোন পেজে কোনটা যাবে সাজিয়ে দাও (keyword map)।`

**সপ্তাহ ৩: পেজ ঠিক করা**
- [ ] `আমার হোমপেজ আর প্রধান ৩টা পেজের title আর meta description লিখে দাও।`
- [ ] `এই পেজের on-page চেকলিস্ট দাও: [পেজের বিষয়]`

**সপ্তাহ ৪: কনটেন্ট আর লিংক**
- [ ] `প্রথম keyword নিয়ে একটা ব্লগ পোস্টের আউটলাইন বানাও।`
- [ ] `আমার মতো নতুন সাইটের জন্য নিরাপদ ২টা backlink কৌশল বলো।`
- [ ] `পরের ৩ মাসের কনটেন্ট ক্যালেন্ডার বানাও।`

৩০ দিন পর Search Console-এ impressions বাড়ছে কিনা দেখুন। ক্লিক আসতে সাধারণত ৩–৬ মাস লাগে, তাই ধৈর্য রাখুন।

## ৪. অভিজ্ঞদের জন্য
**Workflow চালান, একক প্রশ্ন নয়।** router-এ ৭টা multi-skill workflow আছে। নাম ধরে চাইলে AI পুরো ক্রম মেনে কাজ করবে:
- `workflow B অনুযায়ী [সাইট]-এর পূর্ণ অডিট করো: technical → on-page → content → links → AI visibility, তারপর impact/effort অনুযায়ী সাজানো issue list দাও।`
- `workflow E অনুযায়ী ৩ প্রতিযোগীর বিপরীতে AI visibility প্ল্যান দাও।`

**Traffic Drop Doctor সরাসরি চালান।** Python থাকলে:
```
python 3-coding-agents/skills/traffic-drop-doctor/scripts/analyze_gsc.py --export আপনার-compare.zip --dates আপনার-Dates.csv --brand "brand" --events 3-coding-agents/skills/traffic-drop-doctor/references/google-updates.csv --out report
```
আগে ডেমো দিয়ে চেষ্টা করতে চাইলে প্যাকের মূল ফোল্ডার থেকে চালান:
```
python 3-coding-agents/skills/traffic-drop-doctor/scripts/analyze_gsc.py --export 3-coding-agents/skills/traffic-drop-doctor/examples/demo-export.zip --dates 3-coding-agents/skills/traffic-drop-doctor/examples/Dates.csv --events 3-coding-agents/skills/traffic-drop-doctor/examples/events.csv --brand trailpeak --out demo-report
```
এটা ক্লিক কমাকে দুই ভাগে ভাঙে (impressions কমা আর CTR কমা)। তারপর section, query আর device ধরে দেখায় কোথায় কমেছে, মৌসুমি প্রভাব আলাদা করে, migration ধরে, আর কারণগুলো confidence সহ সাজিয়ে দেয়।

**Advanced প্লেবুক** (প্রতিটা skill-এর Learning path-এর Advanced সারিতে):
- keyword clustering at scale (SERP overlap পদ্ধতি)
- large-site migration (log দিয়ে যাচাই, ৪ সপ্তাহের সংক্ষিপ্ত প্ল্যান)
- manual AI visibility audit
- SEO forecasting model (ROI ও payback সহ)
- multi-location operations
- title audit at scale
- schema-markup (রেডি JSON-LD টেমপ্লেট)

**নিজের প্লেবুক যোগ করুন।** নতুন `.md` ফাইল একই কাঠামোয় লিখে `articles/` ফোল্ডারে রাখুন। তারপর সেই skill-এর `SKILL.md`-এর Quick playbooks টেবিলে আর `ARTICLES.md`-এ লিংক দিন। শেষে যাচাই করুন:
```
python tools/validate_skills.py 3-coding-agents/skills --strict
```

## ৫. ফ্রিল্যান্সার ও এজেন্সির জন্য ক্লায়েন্ট workflow
1. **অনবোর্ডিং:** ক্লায়েন্টের Search Console-এ অ্যাক্সেস নিন। তারপর `workflow B অনুযায়ী প্রাথমিক অডিট`।
2. **প্রস্তাব:** `এই অডিট থেকে ৩ মাসের SEO proposal বানাও: স্কোপ, টাইমলাইন, KPI।`
3. **মাসিক কাজ:** keyword map থেকে কনটেন্ট, on-page চেকলিস্ট আর লিংক কৌশল।
4. **রিপোর্টিং:** `এই মাসের Search Console ডেটা থেকে ক্লায়েন্ট রিপোর্ট লেখো, ইংরেজিতে।`
5. **সমস্যা হলে:** traffic-drop-doctor দিয়ে কারণ বের করে ক্লায়েন্ট-রেডি রিপোর্ট দিন।

## ৬. ভালো ফলের নিয়ম ও সীমাবদ্ধতা
- **প্রসঙ্গ দিন।** সাইটের ধরন, দেশ বা শহর, বয়স, ট্রাফিক আর লক্ষ্য বলুন। যত বেশি তথ্য, তত নির্দিষ্ট উত্তর।
- **ফলাফল চেয়ে নিন।** টেবিল, চেকলিস্ট, ড্রাফট বা রিপোর্ট, কোনটা চান তা বলে দিন।
- **যাচাই করুন।** পরিসংখ্যান বিভিন্ন গবেষণা থেকে নেওয়া (২০২৬ পর্যন্ত)। ক্লায়েন্টকে দেওয়ার আগে গুরুত্বপূর্ণ সংখ্যা যাচাই করুন।
- **গ্যারান্টি নেই।** কোনো skill র‍্যাংকিংয়ের নিশ্চয়তা দেয় না। পথ দেখায়, কাজটা করতে হবে আপনাকে।
- **শুধু white-hat।** লিংক কেনা, ভুয়া রিভিউ বা স্প্যাম কৌশল এখানে শেখানো হয় না। এগুলো কেন ঝুঁকিপূর্ণ তা জানতে চাইলে AI বুঝিয়ে দেবে।
- **AI ভুল করতে পারে।** কোনো পরামর্শ অদ্ভুত লাগলে জিজ্ঞেস করুন: `এটা কোন প্লেবুক থেকে বললে? কেন?`
