# ChatGPT / Gemini ব্যবহারকারীদের জন্য

| ফোল্ডার | কোথায় ব্যবহার করবেন |
|---|---|
| `chatgpt-files/` (১৪টা ফাইল) | ChatGPT Custom GPT, ChatGPT Project, Claude Project |
| `gemini-files/` (৯টা ফাইল) | Gemini Gem (এখানে ফাইলের সংখ্যার সীমা কম) |

**সংক্ষেপে:**
1. `chatgpt-files/00-instructions.md` খুলুন। `---` লাইনের নিচের লেখা কপি করে GPT, Project বা Gem-এর **Instructions** ঘরে পেস্ট করুন।
2. বাকি ফাইলগুলো **Knowledge** হিসেবে আপলোড করুন।
3. ChatGPT-তে **Code Interpreter & Data Analysis** চালু রাখুন, Traffic Drop Doctor-এর জন্য দরকার।

বিস্তারিত গাইড: `../docs-bn/03-install-chatgpt-gemini.md`
