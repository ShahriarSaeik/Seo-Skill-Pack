# Claude ব্যবহারকারীদের জন্য

এই ফোল্ডারে ১১টা `.skill` ফাইল আছে। Claude-এ ইনস্টলের নিয়ম:

1. claude.ai → **Settings** → **Capabilities** → **"Code execution and file creation"** চালু করুন।
2. একই পেজের **Skills** অংশে **Upload skill** চাপুন।
3. প্রথমে **`seo-router.skill`**, তারপর বাকিগুলো একটা একটা করে আপলোড করুন।

**নতুনদের জন্য ন্যূনতম সেট:** `seo-router`, `seo-fundamentals`, `keyword-research`, `on-page-seo` (+ লোকাল বিজনেস হলে `local-seo`)।

`.skill` ফাইল আপলোড না নিলে নামের শেষ `.skill` বদলে `.zip` করুন।

বিস্তারিত গাইড: `../docs-bn/02-install-claude.md`
