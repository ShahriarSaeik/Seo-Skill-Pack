# কোডিং AI টুলের জন্য (Claude Code, Cursor, Copilot, Codex, Gemini CLI)

এই ফোল্ডারের তিনটা জিনিস (`AGENTS.md`, `GLOSSARY.md`, `skills/`) আপনার ওয়েবসাইট প্রজেক্টের মূল ফোল্ডারে কপি করুন।

Claude Code-এর জন্য সহজ উপায়: `../install/` ফোল্ডারের স্ক্রিপ্ট চালান।
- Mac বা Linux: `bash install-claude-code.sh`
- Windows: `install-claude-code.ps1`-এ রাইট-ক্লিক করে **Run with PowerShell**

বিস্তারিত গাইড: `../docs-bn/04-install-coding-agents.md`
