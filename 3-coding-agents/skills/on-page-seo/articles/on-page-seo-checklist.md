# A Comprehensive On-Page SEO Checklist for 2026

- **Updated**: 2026-10-05

## TL;DR
An 18-point on-page checklist covering everything from URLs and title tags to AI search optimization and schema. Most items are quick wins; the biggest traffic lever is aligning with search intent (one site saw a 12X traffic jump from one intent fix).

## Framework / Step-by-step
The 18 checklist items:
1. Short descriptive URL
2. Compelling title tag and meta description
3. Title wrapped in H1
4. Gets to the point fast
5. Descriptive subheadings
6. Aligns with search intent
7. Covers the topic in full
8. Has "information gain"
9. Showcases experience and expertise (E-E-A-T)
10. Good readability
11. Passes Core Web Vitals
12. Optimized for AI search (GEO)
13. Optimized for featured snippets
14. Optimized images
15. Internal links TO other pages
16. Useful links to external resources
17. Internal links FROM other pages
18. Relevant schema markup

## Actionable checklist
- [ ] URL: short, descriptive, target keyword as slug (`/on-page-seo-checklist/`)
- [ ] URL: avoid repeated words, dates, and over-specific counts (e.g. "20-best-tips" breaks if you add tip #21)
- [ ] Title tag: specific, benefit-led, matches the page; meta description: expand on the title with more detail
- [ ] Keep title/meta short enough to avoid truncation in SERPs
- [ ] Exactly one H1, wrapping the page title
- [ ] First paragraph delivers what the title promised (definition first for definitional queries; recommendation first for "best X" queries)
- [ ] Rewrite cryptic subheadings for clarity (an AI assistant can do this in seconds); maintain proper H1→H2→H3 hierarchy
- [ ] Verify intent alignment via an intent-classification feature in a keyword research tool or manual SERP review
- [ ] Find common subtopics: manually eyeball top pages, check keyword rankings of top-ranking pages (any SEO tool's competitive analysis report), or use an AI content grader
- [ ] Add something new: original data, expert interviews, templates, tools
- [ ] Flash credentials (author/reviewer expertise) and uniqueness in the first paragraph
- [ ] Run copy through a readability/grammar checker; aim for low reading grade for mass audiences
- [ ] Check Core Web Vitals with a page-speed testing tool; compress/lazy-load images, use CDN, minimize render-blocking JS, set explicit image dimensions
- [ ] Structure content for AI citation: clear headings, short paragraphs, direct answers upfront (inverted pyramid), cite up-to-date sources
- [ ] Hunt featured snippets: find top-10 rankings with snippets you don't own (via an organic keywords report in any SEO tool), then add the missing answer format
- [ ] Images: descriptive filenames, descriptive alt text, compression (any image compression tool)
- [ ] After publishing: add internal links from new page (via an internal link opportunities report in any SEO tool) and TO it (search your site's pages for keyword mentions)
- [ ] Link out to useful external sources for credibility
- [ ] Add schema if top results show rich results (SEO plugins or any schema markup generator); FAQ rich results are now limited to well-known government/health sites and HowTo rich results were removed

## Data points & benchmarks
- Fixing search intent on one site's "backlink checker" page: rankings went from stuck at #5+ to #1; traffic grew ~18K → ~215K monthly visits (12X)
- In one case study, a featured-snippet optimization produced a ~38.9% traffic jump and won 163 additional featured snippets
- Core Web Vitals targets: LCP < 2.5s, INP < 200ms (replaced FID in March 2024), CLS < 0.1
- 54% of US adults read below a 6th-grade equivalent (older survey) — aim for low reading-grade levels for mass-audience content
- Google's information gain patent granted June 2022; helpful content update launched August 2022
- 90% of one large SEO blog URLs are just the target keyword slug

## Mistakes to avoid
- Fluffy intros that delay the promised answer
- Cryptic "clever" subheadings nobody (including Google) understands
- Covering only what competitors cover — no original angle
- Burying your unique data/credentials deep in the post
- Dates and counts in URLs that make content look stale or wrong later
- Ignoring truncation in title tags/meta descriptions

## Key principles
- "If you rank but don't get clicks, revisit your title tag — it's the main piece of information searchers use to decide."
- Matching search intent is prerequisite #1; without it, ranking is "slim to none."
- Google likely values content originality (information gain); bring at least *something* new.
- Most of what helps AI citation (clear structure, direct answers, verifiable facts) is just good traditional SEO.
