# How to Write the Perfect Meta Description

- **Updated**: 2026-10-05

## TL;DR
Meta descriptions aren't a ranking factor and Google showed them only ~37% of the time in one older study — but they're conversion copy for the SERP, social shares, and AI citations. Write them in 5 steps: expand the title, match intent, active voice, concise, deploy.

## Framework / Step-by-step
1. **Expand on your title tag** — add detail, USPs, and reasons to click; don't shoehorn keywords.
2. **Match search intent** — use SERP snippets of top-ranking pages as proxy; copy the pattern (definitions for informational, step-by-step mentions for tutorials). For mixed-intent SERPs, mirror snippets matching your page type.
3. **Use active voice** — start with a verb, make the searcher the subject (exception: definition-style descriptions).
4. **Be concise** — get to the point early since descriptions truncate.
5. **Deploy** — your CMS's meta description field, an SEO plugin, or `<meta name="description" content="...">` in `<head>`. In raw HTML, use `&quot;` instead of quotation marks.

## Actionable checklist
- [ ] Spend effort only on pages that: drive organic traffic, may be shared socially, or get cited by AI platforms
- [ ] Complement, don't repeat, the title tag
- [ ] Mirror snippet patterns from top-ranking results for your intent type
- [ ] Active voice; searcher as subject
- [ ] Front-load value by ¾ of the length so mobile users still see it
- [ ] Homepage deserves extra polish (branded queries = Google most likely to show it)
- [ ] Audit existing pages: crawl the site, join it with organic traffic data, and sort by traffic to see missing or overlong descriptions
- [ ] Fix missing descriptions on the highest-traffic pages first
- [ ] Use bulk-edit options in your CMS or SEO plugin to publish fixes at scale

## Data points & benchmarks
- Google showed the meta description only ~37% of the time (older industry study; varies over time)
- Truncation: 920px (~160 chars) desktop, 680px (~120 chars) mobile
- Example math: 50K impressions/mo → description shown ~18.5K times; CTR 4% → 4.5% = ~100 extra clicks
- Google has experimented with AI-generated snippet text; snippet behavior changes, so don't rely on any one pattern

## Mistakes to avoid
- Keyword-stuffing the description (it's conversion copy, not SEO copy)
- Passive voice ("dull and demotivating")
- Storytelling — every word must earn the click
- Raw quotation marks in hand-coded meta descriptions (breaks the tag)
- Ignoring it entirely: "A weak or missing meta description is effectively an open invitation for the AI to write whatever it thinks best represents your page."

## Key principles
- Write for the reader, not the algorithm; it's "a pitch that convinces the user that the page is exactly what they're looking for."
- Meta descriptions surface in more places than Google: social link previews (team chat apps) and AI assistants' source citations can pull it directly.
- If you set only one description tag, make it the meta description (OG falls back to it).
- CTR math compounds: small CTR gains on high-impression pages produce meaningful click volume.
