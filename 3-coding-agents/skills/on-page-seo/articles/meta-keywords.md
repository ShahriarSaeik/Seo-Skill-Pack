# Meta Keywords: What Are They and Should You Use Them?

- **Updated**: 2026-10-05

## TL;DR
Google has ignored the meta keywords tag since 2009; Bing calls it "dead" (and once used it as a spam signal). Only Yandex (maybe) and Baidu (possibly) still consider it. For 99.9% of sites: don't fill it out — and consider removing it so competitors can't read your target keywords.

## Framework / Step-by-step
**Search engine status of meta keywords:**
- **Google**: ignored since at least 2009 (Matt Cutts video: "we don't use the keywords meta tag in our search ranking")
- **Bing**: "dead in terms of SEO value" (2014, reconfirmed 2020); 2011 hint it may act as a spam signal for low-quality pages
- **Baidu**: 2012 engineer said "garbage heap of history," but 2020 docs say title/description/keywords "are important" — treat as possible signal
- **Yandex**: official docs say it "can be used when determining relevance" — likely low-weight
- **Naver**: zero mention in official docs — assume unused

**Legitimate use cases:**
1. Internal site search powered by search engine software (some enterprise search systems read the tag)
2. Internal keyword tagging system — set the tag to each page's target keyword, then:
   - Prevent keyword cannibalization (check whether a keyword is already targeted by crawling your site and reading each page's tag)
   - Avoid duplicate work across enterprise teams
   - Find collaboration opportunities
3. Competitive intel — about a third of SEOs in a 2020 Twitter poll said they still use the tag; check competitors' homepages for seed keywords to feed into a keyword research tool

**Removal:** crawl your site and filter for pages with a meta keywords tag. Usually set sitewide in the CMS — one code edit removes all. Only worth removing to hide target keywords from competitors; no negative SEO impact otherwise.

## Actionable checklist
- [ ] Don't add meta keywords for Google/Bing rankings
- [ ] Audit whether your CMS/theme auto-adds them (site crawl filtered for the tag)
- [ ] If targeting Russia (Yandex) or China (Baidu): a modest, accurate tag may help
- [ ] Optional: repurpose as an internal keyword-tagging system for cannibalization checks
- [ ] Competitor research: view-source their homepage for seed keywords
- [ ] Focus energy on title tags and meta descriptions instead

## Data points & benchmarks
- Google ignored meta keywords since at least 2009 (Cutts statement)
- ~33% of SEOs polled still used the tag in 2020 (informal Twitter poll)
- Yandex market share ≈ Google's in Russia; Naver handled 74.7% of South Korean searches (older figures)
- Bing 2011: possible spam signal (stuffing = low-quality marker)

## Mistakes to avoid
- Spending time filling meta keywords for Google
- Stuffing the tag (potential spam signal in Bing)
- Leaving competitor-visible target keywords on the page when you care about secrecy
- Ignoring Yandex/Baidu documentation if those markets matter to you

## Key principles
- "For 99.9% of people, the meta keywords tag is useless, and filling it out is a waste of time."
- The tag's only real value today is internal (tagging/site search) or adversarial (competitor spying).
- Title tags and meta descriptions deserve the attention meta keywords get in outdated tutorials.
