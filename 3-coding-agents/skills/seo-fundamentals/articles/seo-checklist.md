# The Only SEO Checklist You Need [Incl. Template]

- **Updated**: 2026-10-05

## TL;DR
Effective SEO checklists are structured by cadence: one-time setup tasks (technical foundation), periodic maintenance (every few months), and per-page tasks for every new publication. Working through these three buckets in order beats one-size-fits-all checklists.

## Framework / Step-by-step

### A. One-time tasks (site foundation)
1. SEO-friendly theme — mobile-friendly, fast, cross-browser, good reviews, regularly updated.
2. Plan site structure — sketch a mind map; every branch is an internal link path.
3. Descriptive URL structure — set it correctly at launch (never bulk-change URLs on an existing site).
4. SEO plugin/CMS settings — sitemaps and meta tags under control.
5. Set up Search Console + webmaster tools accounts (Google and Bing).
6. Create and submit an XML sitemap.
7. Verify indexability — no stray noindex tags on pages you want ranked, especially post-migration.
8. Add Organization/Person schema markup to the homepage.
9. Confirm mobile-friendliness (the Search Console Mobile Usability report was retired in 2023; use Lighthouse/PageSpeed Insights and Chrome DevTools device mode, and check mobile/desktop content parity).
10. Serve over HTTPS (TLS certificate; free options exist).
11. Site accessible at ONE domain — the other three variants must 301-redirect to it.
12. Page speed — pass Core Web Vitals.
13. Set up image compression and modern formats (WebP/AVIF with JPEG/PNG fallbacks).
14. Google Business Profile (local businesses — single highest-ROI free action).
15. Replicate competitors' backlinks — use a link intersect report, but pursue only relevant, reputable sites (skip low-quality directories; paid placements need rel="sponsored").

### B. Periodic tasks (every few months)
- Fix broken pages (404s break UX and authority flow; redirect or restore).
- Refresh declining content — Search Console compare mode, last 6 months vs. previous, sort by clicks difference.
- Content gap analysis — keywords competitors rank for that you don't.
- Update Google Business Profile (hours, holidays, phone, services, posts).
- Scheduled crawls for technical issues; fix new issues as alerts arrive.

### C. Per-page tasks (every new page)
1. Choose ONE primary keyword (check the head topic — usually the highest-traffic variant of the same idea).
2. Assess search intent — dominant content type among top results (post, tool, video, category, product page).
3. Assess ranking difficulty — difficulty score is a rough estimate based on backlinks; also check quality of competitors' links, their topical relevance, big-brand dominance, and content-type feasibility.
4. Research what people want to know — find commonalities/subtopics across top-ranking pages (page-level content gap).
5. Optimize headings — logical H1→H2→H3 hierarchy; include keywords naturally.
6. Hook readers with the intro — PAS formula: Problem, Agitate, Solution.
7. Edit for simplicity — short sentences/paragraphs, plain words, no jargon.
8. Link out to relevant resources when it makes sense (helps users; doesn't hurt SEO).
9. Add purposeful images — break up walls of text; earn Google Images traffic.
10. Optimize images — descriptive filenames, descriptive alt text.
11. Compelling title tag + meta description — title around 60 characters, meta around 155–160 (display limits are pixel-based); include keyword; match intent; no clickbait; add year for freshness-sensitive topics.
12. Short descriptive URL slug — target keyword; shorter is better.
13. Schema markup for rich results where eligible (products, recipes, reviews; FAQ rich results are now limited to well-known government/health sites).
14. Table of contents for long posts — navigation + sitelink eligibility.
15. Internal links to the new page — find existing pages mentioning the keyword; add contextual links.
16. Promote with outreach (optional) — Reverse Skyscraper: find lower-quality competing pages with backlinks; pitch yours as replacement to their linkers.

## Actionable checklist
- [ ] Complete all 15 one-time setup tasks before anything else
- [ ] Calendar quarterly: broken pages, content refresh, content gaps, GBP update, technical crawl
- [ ] Run the 16-step per-page routine on every new publication
- [ ] Never change URL structure wholesale on an established site

## Data points & benchmarks
- Google uses your meta description only some of the time (~63% in one older study) — the title tag matters far more.
- A widely cited estimate says ~50% of the U.S. population reads below an eighth-grade reading level — write simply or alienate half your audience.
- Example: Google Images sent one blog ~20K visits in 3 months — images are a traffic channel, not decoration.
- One refreshed page recovered from a 75K-visit decline over 6 months of neglect — staleness has real cost.

## Mistakes to avoid
- Bulk-changing URL structures on existing sites (causes more harm than good).
- Trusting keyword difficulty scores alone — they only model backlinks.
- Believing external links leak SEO — linking out adds user value.
- Skipping outreach for competitive keywords — "build it and they will come" fails without links.

## Key principles
- Sequence matters: foundation → maintenance → per-page optimization.
- One page, one primary keyword.
- Every periodic task exists because SEO decays: content goes stale, pages break, competitors move.
