# How to Do a Backlink Gap Analysis

- **Updated**: 2026-10-05

## TL;DR
A backlink gap analysis finds websites that link to your competitors but not to you — a pre-qualified prospect list for link building. Prioritize domains linking to all of your competitors, filter for quality (dofollow, decent authority and traffic), manually verify relevance, then run the same intersect at page level for link-insertion outreach.

## Framework / Step-by-step
1. **Identify outperforming competitors** — pull your organic competitors; keep the ones with higher authority than you but a similar site size (comparing against giants yields un-winnable targets).
2. **Intersect referring domains** — find domains linking to 2+ competitors but not to you.
3. **Refine for quality**:
   - Domains linking to ALL competitors you entered → high-priority prospects
   - Domains linking to ≥2 competitors → medium priority
   - Keep dofollow links only
   - If the list is long, set a minimum domain-authority score (e.g., ≥50 on your tool's scale; these are third-party metrics, not Google's) or minimum domain traffic (e.g., ≥1,000 visits/month) — adjust to your niche
4. **Manually check relevance** — open each domain; discard it if it's not about your industry, not a legitimate directory, and not a quality site that would build your brand.
5. **Log prospects in a template** — record domain, authority score, domain traffic, status ("to outreach"), priority tier, and the link target page on your site (homepage if unsure).
6. **Repeat at referring-page level** — switch the intersect to exact pages for strategies that add your link to existing content; editors need the exact URL you're asking to be added to.

## Actionable checklist
- [ ] Pick 2-4 competitors with higher authority and similar site size
- [ ] Run the referring-domain intersect (target = your site)
- [ ] Tier prospects: links to all competitors = high, ≥2 = medium, 1 = low
- [ ] Apply dofollow-only filter; add authority/traffic floors if needed
- [ ] Visit each domain and veto irrelevant or low-quality sites
- [ ] Fill template: authority, traffic, priority, link target, status
- [ ] Re-run the page-level intersect for link-insertion campaigns
- [ ] Hand the finished sheet to outreach with per-domain suggested pages

## Data points & benchmarks
- Quality filter starting points: third-party domain-authority score minimum 50, or domain traffic minimum 1,000/month — tune to results.
- A site that links to every competitor but not to you is the single strongest outreach signal: the topic fit is already proven.

## Mistakes to avoid
- Comparing against competitors far larger than you — the gap list becomes un-winnable.
- Skipping the manual relevance check; filters catch spam, not off-topic sites.
- Outreach without naming the exact page you want a link added to.
- Paying for placements or offering discounts/freebies in exchange for links without rel="sponsored"/nofollow — it breaks Google's link spam policies, and sites that openly sell links are risky prospects.
- Treating the analysis as one-off: competitors earn new links constantly, so refresh quarterly.

## Key principles
- Competitor-linked domains are pre-qualified: they already link to sites like yours.
- Priority = how many competitors the domain links to.
- Relevance beats raw authority every time.
- Domain level finds site-wide prospects; page level finds insertable placements.
