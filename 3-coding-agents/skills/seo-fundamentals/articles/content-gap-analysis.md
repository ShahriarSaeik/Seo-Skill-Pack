# How to Do a Content Gap Analysis

- **Updated**: 2026-10-05

## TL;DR
A content gap analysis finds keywords and topics your competitors rank for that you don't, then turns them into prioritized action items: new pages to create or existing pages to deepen. Method: pull the keyword gap, refine it down to relevant opportunities, then analyze each at domain level and page level.

## Framework / Step-by-step
1. **Find keyword gaps** — compare your domain against 1-3 true competitors; pull the keywords they rank for that you don't. Keep standard organic positions only, excluding alternative result features (image packs, carousels, sitelinks).
2. **Refine and export the data** — if the raw gap exceeds ~100K keywords, trim it:
   - Exclude competitors' brand names (including misspellings and spacing variants, via partial match)
   - Exclude topics irrelevant to your business
   - With multiple competitors, require at least two of them ranking in the top 10 (consensus = real demand)
   - Set minimum monthly search volume (e.g., ≥20)
   - Optionally cap keyword difficulty (e.g., KD under ~20, lower for brand-new sites) to surface low-hanging fruit
3. **Pivot the data** — group keywords by competing page to see which single pages capture which keyword clusters.
4. **Analyze each opportunity** — two gap types:
   - **Domain-level gap**: competitor covers a topic you don't at all → create a new page
   - **Page-level gap**: you both have a page on the topic but theirs ranks for more keywords → theirs is more in-depth; extend yours
   - Check with a `site:` search whether you already have a page on the topic
   - Inspect the missing keywords for common themes (e.g., lots of "what is X" queries → you never defined the term; add that section)
5. **Implement** — log every action item in a tracker with a content brief listing suggested sections and target keywords, so the writer can actually close the gap.

## Actionable checklist
- [ ] List 1-3 competitors that outrank you (an organic-competitors report in any SEO tool works)
- [ ] Export keywords they rank for and you don't (standard organic positions only)
- [ ] Strip competitor branded terms and irrelevant topics
- [ ] Require ≥2 competitors in top 10 when comparing multiple sites
- [ ] Sort by traffic potential, then verify business relevance page by page
- [ ] For each gap: decide new page vs. deepen existing page (site: check)
- [ ] Write a brief per action item: missing keywords + sections to add
- [ ] Re-run the gap analysis quarterly to catch new competitor content

## Data points & benchmarks
- Raw gap reports can exceed 100,000 keywords — always refine before analyzing.
- Example: a competitor page ranking for 120 extra keywords worth 2,187 monthly visits looked tempting — but the keywords were irrelevant to the site's business, so it was skipped. Volume never overrides relevance.
- A page missing simple definitional queries ("what is a landing page") can often close the gap by adding one section.

## Mistakes to avoid
- Chasing every missing keyword regardless of business relevance.
- Stopping at the export — the value is in the page-by-page relevance verdict and the resulting briefs.
- Ignoring page-level gaps because "we already have a page on that" — depth differences are where most recoverable traffic hides.
- Comparing against competitors that aren't really your competitors (different business model or audience).

## Key principles
- Two gap types need two different fixes: domain-level → new page; page-level → deepen/extend.
- Keyword gaps are signals about topic coverage, not a to-do list of individual keywords.
- Consensus filters (multiple competitors ranking) separate real demand from luck.
- The deliverable is a prioritized list of briefs, not a spreadsheet of keywords.
