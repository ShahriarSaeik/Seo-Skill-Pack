# How to Find Your Competitors' Backlinks (And Get Them for Yourself)

- **Updated**: 2026-10-05

## TL;DR
Competitor backlink analysis has three levels: (1) replicate their easy links (directories, listicles, podcasts, guest posts), (2) copy the tactics working for them (journalist-request services, linkable points), and (3) "loot" links they no longer deserve (broken pages, irrelevant 301 redirects, inaccurate content). Start with the easy ones and work down.

## Framework / Step-by-step
**Find backlinks**: free → a free backlink checker (usually a limited top-100 view); paid → a backlink analysis tool with full link lists and filters. Find competitors via the tool's organic-competitors view or the SERPs themselves.

**Level 1 — Replicable links:**
- Directories: run a link-intersect (common backlinks) comparison (your homepage vs competitors') → sites linking to them but not you → eyeball for reputable niche/local directories → sign up and submit (skip bulk or low-quality directories)
- Listicles: a content research tool search `"competitor 1" "competitor 2" "competitor 3" -"your brand"` → pitch authors; pitch asks familiarity ("haven't tried it?") not inclusion — offering a free account is fine, but a gifted product or account means any resulting link should be disclosed and tagged rel="sponsored"/nofollow if given in return, and never pay for list placement without disclosure
- Podcasts/interviews: look up the backlinks to the competitor spokesperson's social profile URL → filter referring URLs containing "podcast"/"episode"/"interview" → pitch same shows
- Guest posts: a content research tool → `topic author:"prolific marketer name"` → one page per domain → pitch same sites

**Level 2 — Copy working tactics:**
- Journalist requests (HARO-style journalist-request services): review the competitor's homepage backlinks → look for quote-style anchors, e.g., repeated expert names → they're responding to journalist requests; do the same
- Linkable points: review the anchor text of links to top-ranking pages → spot cited stats/named concepts/unique frameworks (e.g., a coined named method) → bake coined terms/stats into your content to earn passive links

**Level 3 — Loot links:**
- Broken pages: top pages by links + "404 not found" filter (or a content research tool broken-page filter + RD minimum) → Wayback Machine check → audit link quality → pitch swap
- Irrelevant 301 redirects: top pages by links + "3XX redirect" filter → e.g., an old Penguin-update article redirecting to an unrelated general "Google SEO" page (1.2K RDs) → build relevant replacement → pitch linkers
- Inaccurate content: audit competing pages' claims; where they're wrong (e.g., fake "ranking factors"), tell linkers they're linking to misinformation and offer your accurate resource

## Actionable checklist
- [ ] Build a 3-5 competitor list from the SERPs or an organic-competitors view
- [ ] Link-intersect comparison (homepages) → replicate directory links
- [ ] Quoted-competitor search in a content research tool → shortlist listicles missing you
- [ ] Check backlinks to competitors' spokespeople's social profiles for podcasts
- [ ] Search by author for competitors' prolific guest bloggers; pitch the same sites
- [ ] Scan backlinks for quote anchors → use journalist-request services if they're using them
- [ ] Review anchor text on ranking competitors' pages → identify stats/coined terms to replicate
- [ ] Top pages by links + 404 / 301 filters → build replacement content → outreach
- [ ] Fact-check competing pages your linkers cite; pitch corrections

## Data points & benchmarks
- One older industry survey (2022) ranked guest posting the #3 tactic (47%) — competitors likely use it
- Case: dead SEO-tips page still had **177 RDs** to loot
- Case: irrelevant redirect page with **1.2K RDs** (an old Penguin-update article redirected to a general Google SEO page)
- One SEO statistics list built on linkable points: **1,700+ RDs in under 2 years**
- Coined-term strategy (imitating a named method) earns modest but free passive links

## Mistakes to avoid
- Trying to replicate ALL competitor links — most are impossible like-for-like; triage easy → tactical → lootable
- Paying directory fees for SEO value — only pay if the directory sends customers
- Asking listicle authors directly for inclusion in the first email — build familiarity first
- Skipping link-quality audit before building replacement content for dead pages
- Pitching the same podcasts/interviews without a compelling guest angle

## Key principles
- If a tactic shows up repeatedly in a competitor's profile, it's working for them — systematize it for yourself.
- Linkable points (facts, stats, coined terms) earn links passively — design them into content deliberately.
- Links to outdated/wrong resources are movable: give linkers a better reason to switch.
