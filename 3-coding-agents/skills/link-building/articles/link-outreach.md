# Link Building Outreach for Noobs [With Template]

- **Updated**: 2026-10-05

## TL;DR
Link outreach = find the right prospects, get their emails, send a personalized-but-templated pitch, follow up once. Average conversion is only 1-5%, so volume, relevance, brand, and relationships drive results — not the "perfect" email. Use the "scoped shotgun" approach: template + dynamic variables, segmented per tactic.

## Framework / Step-by-step
1. **Find prospects** — match prospect type to tactic:
   | Tactic | Prospects |
   |---|---|
   | Broken link building | Sites linking to a dead page on your topic |
   | Podcast link building | Niche podcast hosts |
   | Skyscraper | Sites linking to an "inferior" page |
   | Unlinked mentions | Sites that mentioned you without linking |
   | Guest blogging | Sites likely to accept pitches (multi-author sites) |
   | Resource page link building | Curators of industry resource pages |
   Example (guest posts): a content research tool → topic title search → English → 500+ words → one result per site → prioritize multi-author sites.
2. **Find contact details** — an email-finder tool (single lookups or bulk via CSV/spreadsheet).
3. **Send a personalized pitch** — answer 3 questions: Why open (subject line)? Why read (short body, hook)? Why link (what's in it for them)?
4. **Follow up once** — short and polite; more is spam. No interest = stop.

## Actionable checklist
- [ ] Define the tactic before prospecting; build the matching prospect list
- [ ] Verify the person you email controls the page (not a guest author!)
- [ ] Get names/domains right — wrong name = instant delete
- [ ] Build a template with dynamic variables (any outreach tool), segment per campaign
- [ ] Answer the 3 questions for every email you write
- [ ] Send one follow-up, then move on
- [ ] Scale volume: 1,000 emails at 1% = 10 links
- [ ] Invest in brand + relationships between campaigns (DMs, calls, small thank-you gestures — practitioner advice; keep gifts modest and never tied to a link)

## Data points & benchmarks
- Informal poll of 800+ people (X + LinkedIn): average outreach conversion rate **1-5%**
- One case study: 515 emails → **17.55% reply rate**, roughly **5.7% conversion** (brand-boosted)
- One team ran hyper-personalized campaigns that got **zero results** — over-personalization ≠ better
- Volume math: 100 emails @1% = 1 link; 1,000 @1% = 10 links

## Mistakes to avoid
- Using templates seen everywhere (instant delete), or getting the recipient's name/site wrong
- Pitching authors of old guest posts who don't control the site
- Over-personalizing every email — diminishing returns, wastes time
- Multiple follow-ups hoping for a different answer
- Blaming tactics for low rates when the list is irrelevant or the brand is unknown
- Offering money, gifts, or free product for a link without disclosure — tag such links rel="sponsored" or nofollow

## Key principles
- "Good link outreach is indistinguishable from good business development" — right partners, strong brand, existing relationships, right ideas.
- People don't do favors for strangers; brand solves the stranger problem.
- A strong brand = "consistent output of high-quality work that people enjoy" (practitioner advice).
