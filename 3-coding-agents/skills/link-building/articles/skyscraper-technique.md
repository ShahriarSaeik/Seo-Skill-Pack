# How to Execute the Skyscraper Technique (And Get Results)

- **Updated**: 2026-10-05

## TL;DR
The Skyscraper Technique (popularized 2015): find content with lots of backlinks, make a better version, reach out to its linkers. It can still work (61% of 1,242 SEOs in one informal poll agreed) but is oversaturated — success now depends on avoiding the 5 common failure modes: copied templates, unsegmented prospects, too few prospects, "bigger = better" thinking, and ignoring brand.

## Framework / Step-by-step
1. **Find relevant content with lots of backlinks** — three methods:
   - a backlink analysis tool → top pages by backlinks (target pages with 50+ referring domains; ignore homepages)
   - a content research tool → topic search + RD filter ≥50 + language filter + exclude homepages
   - a keyword research tool → keyword ideas for your topic + keyword difficulty filter ≥40 (some tools base difficulty on the referring domains of the top 10 pages, so high difficulty often = link-heavy SERPs)
2. **Make it better** — The 4 improvement axes: Length (more tips), Freshness (new stats/screenshots), Design (custom/interactive), Depth (actionable detail, not bare lists)
3. **Reach out to the right people** — only sites that linked to the original piece. Find them via a backlink analysis tool (filters: language, followed links). Then mine linkers of ALL top-ranking pages for the same topic, not just the one you copied.

## Actionable checklist
- [ ] Shortlist 50+ RD pages via top pages by backlinks / a content research tool / difficulty ≥40 terms
- [ ] Improve along Length/Freshness/Design/Depth — but only where it adds reader value
- [ ] Pull the original page's backlinks; filter followed + language
- [ ] Segment prospects by link context using anchor text; write a pitch per segment referencing what THEY cited
- [ ] Expand prospect list with linkers to every top-10 page for the keyword
- [ ] Write your own template; never send the widely copied original 2015 template verbatim

## Data points & benchmarks
- Informal poll of 1,242 SEOs (Twitter + LinkedIn): **61%** say the technique still works
- One industry survey: only **18%** of SEOs still used it — ranked **#20** among tactics (oversaturated)
- Opportunity thresholds used: **50+ referring domains** for target content; **keyword difficulty ≥40** for SERP-based discovery
- The original skyscraper case study reportedly earned **10,000+ backlinks** (a self-reported outlier)
- Case: a niche-site-ideas post with only **10 ideas** outranks longer skyscraper listicles — expertise beats length

## Mistakes to avoid
- Sending the original 2015 template word-for-word — instantly deleted
- One generic pitch to all linkers — people link for different reasons
- Only replicating one page's backlinks — too small a pool; link building is a numbers game
- Arms-race padding (25 → 50 → 100 items) — "curation is where the value is"
- Improving for improvement's sake (bumping publish date, adding mediocre tips) — ask "does this give more value?"

## Key principles
- "Better does not occur in a branding vacuum" (a well-known link-building saying) — people often link because of WHO published it, not having read it.
- A single skyscraper doesn't make a city: consistent high-quality output builds the brand that makes outreach convert.
- Ask before publishing: "What makes my content unique and link-worthy?"
