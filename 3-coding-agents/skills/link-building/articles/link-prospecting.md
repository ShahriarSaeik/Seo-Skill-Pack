# Link Prospecting: How to Find Quality Backlinks for Your Website [With Template]

- **Updated**: 2026-10-05

## TL;DR
Link prospecting = finding and vetting potential link sources before outreach. Five steps: pick tactic → set evaluation criteria → find prospects (competitor analysis, Google operators, a content research tool) → vet quality manually (metrics lie — spam sites fake them) → find contacts. Prospecting decides campaign success; bad lists waste everything downstream.

## Framework / Step-by-step
1. **Consider your link building strategy** — prospects differ per tactic: guest blogging (sites open to guest authors), niche edits (paid insertions are advertising — must be tagged rel="sponsored"/nofollow), journalist-request services, skyscraper (competitor analyses), digital PR, linkable assets.
2. **Set evaluation criteria** — Relevance (topical for authority, geographical for local SEO), authority score (backlink strength on the tool's scale), Organic traffic (quality + non-manipulated profile signal — high authority + zero traffic = avoid), Traffic value (the tool's estimate of what the traffic is worth).
3. **Find prospects** — three methods:
   - Competitor analysis: organic competitors → link-intersect comparison (domains linking to several competitors, not you); top pages by links to see what content earns links; backlinks to each competing top-ranking page → filter + export
   - Google operators + an SEO browser extension (authority metrics shown in SERPs): "contribute", "guest blogging spot", "guest contributor", `inurl:guest*author`, `"guest article" + inanchor:contact`
   - A content research tool: page-level search (niche-edit targets; a browser extension or link checker finds broken links), author-level search (digital PR influencers), authority/traffic/traffic-value filters, export; also useful for pages with keyword anchors, topic blogs accepting guest posts, and unlinked brand mentions (export + request link)
4. **Evaluate quality** — apply criteria, then MANUALLY check each site: metrics can be manipulated (link-selling farms fake authority scores). Spam tells: thin/poor content, bad design, more ads than content, no about/author pages, posts by "Editorial team", excessive outbound links.
5. **Find contacts** — an email-finder tool by domain; no valid email = drop the prospect. Feed the list into an outreach/CRM tool.

## Actionable checklist
- [ ] Write down tactic + evaluation thresholds BEFORE searching
- [ ] Target thresholds to start: relevance, authority 40-80, organic traffic 1,000+/mo, traffic value $1,000+ (adjust to your niche)
- [ ] Build prospect sheet from 2+ methods (competitor + operator search)
- [ ] Spot-check every site manually for the 6 spam signals

- [ ] Expand list with "lookalike" domains of good prospects

## Data points & benchmarks
- One practitioner's qualification thresholds: **authority 40-80, traffic ≥1,000/mo, traffic value ≥$1,000**
- High authority + zero organic traffic = red flag for manipulated metrics
- Google actively works to "neutralize the impact of unnatural links" — intentional links only

## Mistakes to avoid
- Using metrics alone to qualify sites — manipulated authority scores are common among link sellers
- Skipping manual site visits — one example passed all criteria but was an ad-farm
- Mixing prospect types across tactics (guest post lists ≠ skyscraper lists)
- Pitching irrelevant sites because competitors link there — relevance still rules

## Key principles
- "Without prospecting, every other aspect will likely fall to pieces."
- Quality over quantity — a few intentional, relevant links beat masses of random ones.
- Competitor-linked sites pre-qualify themselves: they already linked to sites like yours.
