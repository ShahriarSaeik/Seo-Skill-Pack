# How to Target Keywords With Blog Posts (& Get More Search Traffic)

- **Updated**: 2026-10-05

## TL;DR
Ranking posts deliver traffic for years (a 2018 post still pulls consistent traffic), but only if you write what people search for. Target keywords in 3 steps: find ideas (traffic potential high, KD low), match the three Cs of search intent from the SERP, then create content that covers the expected subtopics with good on-page basics.

## Framework / Step-by-step
1. **Find keyword ideas** — run seed keywords through a keyword research tool's phrase-match ideas, then filter to questions (coffee seeds → hundreds of thousands of ideas). Filter for beginners: HIGH Traffic Potential + LOW KD. Pick relevant ones.
2. **Identify search intent** — study current top-ranking pages for the three Cs: content type (blog posts), content format (how-to, listicle, review), content angle (current year, "for beginners", "with vinegar"). E.g., "how to clean coffee maker" = blog post + how-to guide + vinegar angle.
3. **Create the content** (3 parts):
   - **A. Cover important subtopics** — run a content-gap comparison on 3–4 top-ranking URLs (leave your own site out) and keep keywords that 3 or all 4 of them rank for → common keywords = subtopics searchers expect; use them as H2s (e.g., "what is earned media," "earned media examples," "paid vs earned media").
   - **B. Reader experience** — descriptive H2–H6 subheadings, bullets for skimming, images/GIFs to break text, short sentences/paragraphs, simple words, conversational tone, read aloud when editing.
   - **C. On-page basics** — keyword in title (or close variation; never shoehorn), short descriptive URL slug, compelling meta description (CTR, not ranking), descriptive alt text, internal + external links to relevant resources.

## Actionable checklist
- [ ] Generate question keywords from seeds; filter TP high / KD low
- [ ] Note the three Cs of the SERP before outlining
- [ ] Run a content-gap comparison on the top 3–4 URLs (keywords shared by 3+) to extract mandatory subtopics → H2 outline
- [ ] Apply readability rules (short paragraphs, skimmable, conversational)
- [ ] Title includes keyword (or variation); slug = short keyword; meta description sells the click
- [ ] Add alt text; include relevant internal and external links

## Data points & benchmarks
- Coffee blog seeds → hundreds of thousands of question keywords in phrase-match keyword ideas
- 2018 post (Google search operators) still generates consistent organic traffic years later
- "how to clean coffee maker" SERP: all blog posts, mostly how-to format, "with vinegar" recurring angle
- Google has said headings help it understand a page (2020)

## Mistakes to avoid
- Publishing whatever you feel like and hoping search traffic shows up
- Keyword stuffing — ancient, doesn't work
- Skipping the SERP's dominant format/angle when planning the post
- Omitting subtopics every top page covers
- Shoehorning exact-match keywords into titles when a variation reads better

## Key principles
- Consistent organic traffic comes from writing about things people actually search.
- The SERP is your outline: type + format + angle + common subtopics.
- Content earns rankings by relevance and completeness; on-page SEO is the icing, not the cake.
