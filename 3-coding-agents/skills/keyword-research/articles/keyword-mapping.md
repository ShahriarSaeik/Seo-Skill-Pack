# Keyword Mapping for SEO: How To Do It (Plus a Simple Sheet Layout)

- **Updated**: 2026-10-05

## TL;DR
A keyword map assigns every target topic to exactly one page on your site, telling you what to create, what to optimize, and what to leave alone. Build it in 6 steps: find keywords → cluster into topics → map to URLs → pick secondary keywords → set an action per topic → assign owners.

## Framework / Step-by-step
1. **Find keywords** — run seeds through a keyword research tool for phrase-match keyword ideas; filter (low KD, low-authority sites in the top 5, modifiers) to taste.
2. **Group into topics** — use parent-topic grouping (e.g., "best coffee for cold brew" cluster = 43 same-intent keywords). Same intent = one page.
3. **Map topics to pages** — record topic + KD + traffic potential (TP, from the parent topic's metrics) in your mapping sheet. If a page exists, add its URL. Check existence with `site:yourwebsite.com [parent topic]`. Prioritize topics with BOTH traffic potential (TP; e.g., "best coffee maker" TP = 28K) and business potential (subjective: affiliate site = high; coffee roaster = low for the same keyword).
4. **Pick secondary keywords** — cluster members that add intent nuance but don't merit standalone pages. Decision rule: if a dedicated result exists for the sub-keyword but gets ~no traffic → make it a secondary keyword; if a dedicated result gets LOTS of traffic (e.g., "best burr grinder") → standalone page.
5. **Set an action per topic** — no page → **Create**; page ranks outside top 5 for primary/secondaries or misses a subtopic → **Optimize**; ranks well + covers topic → **No action**. Optimization includes content additions (e.g., add ground-coffee picks if missing) and internal links (find pages that already mention the secondary keyword and link them to the target page).
6. **Assign each topic** — assign an owner in your tracking sheet; track traffic trends per URL set.

## Actionable checklist
- [ ] Export clusters into a keyword map sheet (columns: topic, KD, TP, URL, secondaries, action, assignee)
- [ ] Run `site:` searches to find existing pages per topic
- [ ] Score traffic potential (TP) + business potential before committing
- [ ] Apply the secondary-keyword decision rule for each meaningful cluster member
- [ ] Check current rankings for each topic's keywords (rank tracker or Search Console); anything outside the top 5 → mark Optimize
- [ ] Fix Optimize items: close subtopic gaps + add internal links with relevant anchors
- [ ] Track traffic trends per URL set to measure whether the map's actions move traffic

## Data points & benchmarks
- "best coffee for cold brew" cluster: 43 keywords on one page
- "best coffee maker" topic: TP = 28K monthly visits (top page)
- Optimization trigger: any primary/secondary keyword ranking outside top 5
- Coffee seeds → millions of keywords in phrase-match keyword ideas

## Mistakes to avoid
- Creating separate pages for same-intent variations (cannibalization)
- Mapping topics without business-potential filtering
- Forcing low-traffic sub-keywords onto standalone pages
- Marking "No action" without checking per-keyword rankings
- Building the map and never executing the action column

## Key principles
- One topic, one page — the map's core invariant.
- Secondary keywords exist to inform content depth, not to justify new URLs.
- A keyword map is a living workflow doc (create/optimize/no-action + owners), not a one-time spreadsheet.
